# RuoYi-App-vue3 前后端接口集成指南

## 1. 概述

本文档介绍了RuoYi-App-vue3项目中新增的短信验证码登录功能，以及前后端接口集成的相关说明。

## 2. 新增功能

### 2.1 短信验证码登录功能
- 支持手机号+短信验证码登录
- 支持账号/手机号+密码登录
- 提供登录方式切换功能

### 2.2 页面结构
- `/pages/login.vue` - 登录主页面（支持两种登录方式切换）
- `/pages/login/code.vue` - 短信验证码输入页面

## 3. 前端实现说明

### 3.1 API 接口调用
前端已实现以下新接口的调用：

1. `/api/login.js` 中新增：
   - `getSmsCaptcha(mobile)` - 获取短信验证码
   - `smsLogin(mobile, code)` - 短信验证码登录

2. `/store/modules/user.js` 中新增：
   - `smsLoginAction(mobile, code)` - 短信登录方法

### 3.2 页面流程
1. 用户在登录页面输入手机号，点击"获取短信验证码"
2. 调用 [getSmsCaptcha](file://e:\RuoYi-App-vue3\RuoYi-App-vue3\api\login.js#L52-L61) 接口发送验证码
3. 跳转到验证码输入页面
4. 用户输入验证码后，调用 [smsLogin](file://e:\RuoYi-App-vue3\RuoYi-App-vue3\api\login.js#L63-L73) 接口完成登录
5. 登录成功后获取用户信息并跳转到首页

## 4. 后端需实现接口

### 4.1 接口规范
请参考 [sms-api-spec.md](file://e:\RuoYi-App-vue3\RuoYi-App-vue3\docs\sms-api-spec.md) 文件，其中详细说明了后端需要实现的接口规范。

### 4.2 接口地址
- 获取短信验证码：`POST /auth/sms`
- 短信验证码登录：`POST /auth/smsLogin`

## 5. 集成步骤

### 5.1 后端开发
1. 实现短信验证码发送功能
2. 实现短信验证码验证和登录逻辑
3. 配置短信服务商（如阿里云、腾讯云等）
4. 实现验证码有效期和发送频率限制

### 5.2 测试验证
1. 验证短信验证码发送功能
2. 验证短信验证码登录功能
3. 验证错误处理逻辑
4. 验证安全限制（频率限制、错误次数限制等）

### 5.3 前端适配
后端接口实现完成后，前端将自动适配，无需额外修改。

## 6. 注意事项

1. 安全性：确保验证码有效期限制和发送频率限制
2. 用户体验：提供清晰的错误提示
3. 兼容性：保持与现有登录方式的兼容
4. 测试：充分测试各种边界情况

## 7. 故障排除

### 7.1 常见问题
- 验证码无法发送：检查后端接口是否实现
- 登录失败：检查后端接口返回格式是否符合规范
- 页面跳转异常：检查路由配置

### 7.2 调试方法
1. 使用浏览器开发者工具查看网络请求
2. 检查控制台错误信息
3. 验证API返回的数据格式
