# 短信验证码登录接口规范

## 1. 获取短信验证码接口

### 接口信息
- **接口地址**：`/auth/sms`
- **请求方式**：`POST`
- **接口描述**：向指定手机号发送短信验证码

### 请求参数
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| mobile | String | 是 | 手机号码 |

### 请求示例
```json
{
  "mobile": "13800138000"
}
```

### 响应参数
| 参数名 | 类型 | 描述 |
|--------|------|------|
| code | int | 状态码 |
| msg | String | 响应消息 |
| data | Object | 响应数据 |

### 响应示例
```json
{
  "code": 200,
  "msg": "验证码发送成功",
  "data": null
}
```

## 2. 短信验证码登录接口

### 接口信息
- **接口地址**：`/auth/smsLogin`
- **请求方式**：`POST`
- **接口描述**：使用手机号和短信验证码进行登录

### 请求参数
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| mobile | String | 是 | 手机号码 |
| code | String | 是 | 短信验证码 |

### 请求示例
```json
{
  "mobile": "13800138000",
  "code": "123456"
}
```

### 响应参数
| 参数名 | 类型 | 描述 |
|--------|------|------|
| code | int | 状态码 |
| msg | String | 响应消息 |
| data | Object | 登录成功后的数据 |
| data.token | String | 认证令牌 |

### 响应示例
```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzUxMiJ9..."
  }
}
```

## 3. 验证码有效期和限制

### 验证码规则
- 验证码长度：6位数字
- 验证码有效期：5分钟
- 同一手机号发送间隔：60秒
- 同一手机号每日发送上限：10次

### 安全限制
- 验证码错误次数限制：5次/分钟/手机号
- 频繁发送限制：1小时内最多发送20次

## 4. 错误码定义

| 错误码 | 描述 |
|--------|------|
| 5001 | 手机号码格式错误 |
| 5002 | 手机号码不能为空 |
| 5003 | 验证码发送过于频繁 |
| 5004 | 验证码已失效 |
| 5005 | 验证码错误 |
| 5006 | 今日发送次数已达上限 |

## 5. 实现建议

### 后端实现要点
1. 验证手机号格式
2. 限制发送频率
3. 存储验证码到Redis（设置过期时间）
4. 验证码使用后立即失效
5. 实现错误次数限制

### 业务逻辑
1. 用户首次使用手机号登录时，如果用户不存在则自动创建账户
2. 验证码登录成功后返回JWT token
3. 验证码登录成功后，同样需要获取用户信息（参考已有接口）
