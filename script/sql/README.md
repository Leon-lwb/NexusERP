# 数据库脚本入口

截至2026-10-19，仓库中的 `ry-vue.sql`、`ry-erp.sql`、`ry-mes.sql` 为所有者提供的本地测试数据库完整导出，按明确指示原样提交；`ry-iot.sql`沿用当前工作区版本。四库的日期快照、摘要和恢复说明见[2026-10-19完整测试快照](snapshots/2026-10-19/README.md)。

| 文件 | 数据源 | 当前表数 |
| --- | --- | ---: |
| `ry-vue.sql` | 系统库/master：用户、权限、AI、Flow、工程设备、签章、报表等 | 216 |
| `ry-erp.sql` | ERP业务库 | 162 |
| `ry-mes.sql` | MES业务库 | 89 |
| `ry-iot.sql` | IoT业务库 | 16 |

完整测试导出保留本地配置与运行数据。若需要只含结构和公开初始化种子的历史系统库基线，使用[2026-10-17公开快照](snapshots/2026-10-17/README.md)，其内容和摘要不等于最新主SQL。

四个主脚本含 `DROP TABLE`，只用于全新空库或明确授权的隔离恢复；实际库名与导入顺序以目标配置为准。存量环境先核对基线、备份和[数据库增量变更记录](../../doc/system/数据库增量变更记录.md)，按需使用 `update/` 中的迁移，禁止把主脚本直接重导到现有业务库。

本次连接器配对修复无需SQL迁移。Windows客户端安装和升级见[桌面使用说明](../../ruoyi-extend/nexus-engineering-connector/desktop/使用说明.md)，不要为配对故障导入数据库备份。
