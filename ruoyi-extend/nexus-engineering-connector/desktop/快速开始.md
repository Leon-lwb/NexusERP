# Nexus 工程连接器 Windows 快速开始

适用版本：**0.1.0**；文档日期：2026-10-19。完整操作、地址示例和故障排查见同目录的 [使用说明](使用说明.md)。

## 使用前准备

- Windows 10 22H2 / Windows 11，x64，已安装 .NET Framework 4.8。桌面包捆绑 Node.js **24.21.0**，无需另装 Node 或 npm。
- 先单独安装嘉立创 EDA **专业版**，正常打开并完成首次初始化；连接器不包含 EDA。
- 管理员已启用 Nexus 前后端工程功能，配置专用私有 OSS，分配工程权限并启用“嘉立创EDA工程工具”。开发开关已启用，生产仍需显式配置。
- 后端须包含 **2026-10-19 Redis `global` 配对键修复**。多实例要全部更新后再生成新码；仅更换客户端包不能修复此问题。本次发行与该修复无需 SQL 迁移。

## 首次使用

1. 从 [Nexus-ERP Gitee 仓库](https://gitee.com/NexusERP/nexus-erp) 的 [工程连接器 0.1.0 发行版](https://gitee.com/NexusERP/nexus-erp/releases/tag/engineering-connector-v0.1.0) 下载 `nexus-engineering-connector-0.1.0-win-x64-desktop.zip` 和同名 `.sha256` 文件。在 PowerShell 中运行下列命令，将计算结果与校验文件中的摘要核对；不一致时停止使用。

   ```powershell
   Get-FileHash -LiteralPath '.\nexus-engineering-connector-0.1.0-win-x64-desktop.zip' -Algorithm SHA256
   Get-Content -LiteralPath '.\nexus-engineering-connector-0.1.0-win-x64-desktop.zip.sha256'
   ```

2. **完整解压**到固定目录，例如 `C:\Apps\NexusEngineeringConnector`。保留 `runtime`、`dist`、`node_modules`、`templates`、`scripts` 和 EXE 配置文件；不要只复制 EXE 或在压缩包内启动。ZIP 已同时内置 `快速开始.md` 和 `使用说明.md`，解压后可直接查阅；Gitee 发行页也提供两份文档的独立附件。
3. 双击 `NexusEngineeringConnector.exe`。本版尚未数字签名；若出现 SmartScreen 提示，先确认 Gitee 来源、版本和 SHA-256。只有核实来源且符合单位策略时，才按提示查看“更多信息”并决定是否继续；策略阻止时联系管理员。无需关闭安全保护或使用管理员权限。详细处理见 [使用说明](使用说明.md)。
4. 在“Nexus 服务地址”填写站点根地址或 API 基地址，如 `http://nexuserp.website`、`http://nexuserp.website/prod-api`。本机开发可用 `http://localhost:80/dev-api` 或直连 `http://localhost:8080`。点击“浏览…”选择已安装的嘉立创 EDA 专业版 EXE，再点击“保存设置”。
5. 点击“检查 EDA”，确认显示“EDA 连接检查通过”。它只检查本机编辑器；`CLI_COMPAT` 表示当前使用 CLI 兼容模式，不代表嘉立创原生 MCP 已可用。
6. 登录**同一 Nexus 环境**，进入“工程设备”，点击“配对新设备”，复制网页生成的**五分钟一次性配对码**。复制按钮不可用时，在网页文本框中选中后按 `Ctrl+C`，回到连接器粘贴；不要复制浏览器 Token。
7. 点击“配对设备”，看到“配对成功”后点击“启动连接器”。在网页刷新设备列表，分别确认设备在线、编辑器已连接和实际传输模式。连接器窗口显示“运行中”仅表示工作进程已启动。
8. 在 Nexus AI 对话中主动选择此工程设备，先发起连接检查；再按需发起 PCB 草稿任务。通过任务卡片查看实际检查结论、任务状态和产物。

## 日常操作

首次配对完成后，后续双击应用会自动启动已绑定的连接器；这不表示 Windows 开机自启。可以给 EXE 创建桌面快捷方式。

- 关闭窗口右上角的 `×` 会收至系统托盘，连接器继续运行。双击托盘图标或选择“打开窗口”恢复。
- “停止”或托盘“停止连接器”用于停止本次工作；完全退出须在托盘选择“退出应用”。正常停止超过 **10 秒**会终止本次自有 Node 工作进程，并提示到 Nexus 核对任务；不会强杀用户的 EDA，也不会删除源工程。
- “打开工作目录”可查看保留的工程。配置为 `%LOCALAPPDATA%\Nexus\EngineeringConnector\config.json`，身份和工程在其 `workspace` 下。身份使用 **DPAPI CurrentUser** 加密，配对码不落盘；换 Windows 用户不能直接复用身份，修改 Nexus 地址后须重新配对。
- 升级前从旧应用托盘退出，将新版完整解压到新目录，再启动并更新快捷方式。卸载程序目录会保留上述用户数据；工程备份和解绑方法见 [使用说明](使用说明.md)。

## 遇到问题

`PAIRING_INVALID`：在网页重新生成新码；若新码立即失败，让管理员先核对上述后端修复及所有实例。`ENGINEERING_DISABLED`：核对后端工程开关和部署。`API_NOT_FOUND`：核对 API 前缀。`API_UNREACHABLE`：核对地址、端口和网络。`PROTOCOL_UNSUPPORTED`：由管理员协调更新前后端与连接器。完整诊断表见 [使用说明](使用说明.md)。

首次使用须在目标 Windows / EDA 环境完成连接检查和所需任务验证。演示模板仍是工程草稿，DRC 违规必须保留并由工程师审核，不能直接用于投产。
