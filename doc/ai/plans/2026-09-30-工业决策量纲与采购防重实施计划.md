# 工业决策量纲安全、采购来源防重 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按已批准的 `doc/ai/specs/2026-09-30-工业决策量纲与采购防重规格.md` 顺序封闭旧 AI 采购执行入口、建立 ERP 逐来源且量纲可信的采购意图、替换跨单位排名。

**Tech Stack:** Java17、Spring Boot3.5、MyBatis-Plus/dynamic-datasource/MySQL（现存 MySQL5.7 部署兼容）、Vue3/TypeScript、JUnit5、Maven、Node20。
