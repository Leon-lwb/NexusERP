# 嘉立创 EDA 本地连接器实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `executing-plans`；先完成 C1–C2 的真实客户端能力验证，再执行 C3–C6。

**Goal:** 提供轻量 Windows 工程连接器，主动领取 Nexus 任务，通过本机嘉立创 EDA MCP 创建模板草稿、导出文件并上传，断线后不重复写入工程。

**Architecture:** 独立 Node.js/TypeScript CLI，设备凭证经 Windows DPAPI 保存；任务通过 HTTPS 短轮询，嘉立创 MCP 通过子进程 STDIO 访问。软件适配器把固定动作映射为随包审查的 API 调用，服务端和模型均不能传入任意脚本。

**Tech Stack:** Node.js 24 LTS / TypeScript / MCP TypeScript SDK / Node test runner / Windows DPAPI。

## 1. 项目形态与产物

代码放在 `ruoyi-extend/nexus-engineering-connector/`，使用独立 package-lock，不进入 Maven 聚合。首期四个命令：`doctor` 检查环境，`pair` 通过 stdin 兑换配对码，`run` 执行任务，`unpair` 撤销并清理凭证。提供一个解压即用的 Windows 分发目录；通过安装好的 Node.js 24 运行，不在本期制作 Electron、系统服务、托盘或开机自启。

连接器对外函数、参数、MCP 脚本入口使用中文 JSDoc；PowerShell DPAPI 脚本使用中文帮助注释。仓库中只有脱敏配置示例和合成测试文件，没有真实 Token、客户电路或本机配置。

- [ ] **1. 写失败用例。** 401 停止领取，刷新旋转后旧凭证不可用；请求重定向到其他主机被拒绝；超时可中止；子进程参数含空格/引号时仍是单独 argv；MCP isError=true 不算成功。
- [ ] **2. 实现配对。** 从 stdin 读取一次性码，不让码出现在命令历史或日志；验证响应协议。refreshToken 用 CurrentUser DPAPI 保存，原文只在进程内存。PowerShell helper 从 stdin 读入，`shell:false`、`windowsHide:true`，不得把秘密拼进 argv；加密失败即拒绝持久化，不回落明文。
- [ ] **3. 实现 HTTP。** 内置 fetch 使用 `redirect:'error'` 和 AbortSignal；只调用协议固定路径，携带设备头；同时检查 HTTP 状态和 R.code。默认重试 1/2/4/8/16 秒加抖动，401/403 不自动恢复。
- [ ] **4. 实现本机 MCP。** SDK `Client` 配合 `StdioClientTransport` 启动真实 exe，参数 `['--mcp','stdio']`；初始化后发现工具 schema，并限制为 C2 已审工具。不会把 Nexus 服务器上的 STDIO 工具误认为工程师设备。

```typescript
/** 启动本机嘉立创MCP；只使用配置校验后的可执行文件和固定参数。 */
const transport = new StdioClientTransport({
  command: executable,
  args: ['--mcp', 'stdio'],
  stderr: 'pipe'
});
```

这里的 `executable` 由 `config.ts` 校验，连接的 Client 和 Transport 均由 `mcp-client.ts` 拥有并关闭；从 MCP 返回的文本只是数据，不作为后续权限指令。

- [ ] **5. 用 fake MCP 跑行为测试。** 验证初始化、发现、错误、超时、取消、断管和退出时清理；不匹配实际版本直接失败，输出兼容性诊断。
