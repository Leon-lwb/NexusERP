# 嘉立创 EDA 前端预览与联调实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `executing-plans`；F1–F4 可使用合成产物，F5 必须另记真实客户端证据。

**Goal:** 在 Nexus 提供设备与任务入口，在 AI 对话中显示实际任务卡片，并查看 PNG 线路图、BOM/DRC、OBJ/MTL/纹理和源工程下载。

**Architecture:** 页面通过现有 request 和服务端鉴权接口读取任务及产物，Three.js 使用受控 manifest 加载 OBJ 资源。聊天只负责入口和提醒，任务状态和预览不依赖对话窗口内存。

**Tech Stack:** Vue 3 / TypeScript / Element Plus / Three.js / Node test runner / esbuild。

## 1. 路由、数据和验证方式

设备与任务菜单由 B1 SQL 注册；前端页面不在本期通过运行 SQL 自动安装。列表菜单对应 `ai/engineering/device/index`、`ai/engineering/task/index`；预览详情使用鉴权隐藏路由 `/ai/engineering/task/:taskId`。数据库中的菜单权限和后端权限必须同时验证。

前端保持所有 ID 为 string，数值坐标/数量不强转 JS Number 参与业务计算。纯函数与异步请求门禁使用既有 Node + esbuild 行为测试；Three.js 几何可以在 Node 中解析，WebGL 渲染在浏览器检查。测试须断言实际结果、请求与资源释放，不用扫描源码字符串代替交互测试。

```javascript
test('保留雪花ID并阻止旧任务响应覆盖新任务', () => {
  const gate = new EngineeringRequestGate();
  const oldRequest = gate.begin('9223372036854775807');
  const currentRequest = gate.begin('2000000000000000002');
  assert.equal(gate.isCurrent(oldRequest), false);
  assert.equal(gate.isCurrent(currentRequest), true);
  assert.equal(currentRequest.taskId, '2000000000000000002');
});
```

`EngineeringRequestGate` 在 `model.ts` 定义，提供 `begin(taskId)`、`isCurrent(token)`、`invalidate()`；token 保存 taskId 和递增请求代数。
