# 嘉立创 EDA 后端任务与产物实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 `executing-plans`；按 B1–B6 顺序执行，完成一项再推进下一项。

**Goal:** 建立可被模拟连接器独立验证的设备绑定、任务领取、私有产物上传与读取，并将 AI 工程工具接入既有工具管理。

**Architecture:** 契约和共享实体位于 common-ai；业务位于 ruoyi-ai；system 通过 Port 实现用户身份与私有 OSS 适配。全部元数据走 master，外部 IO 与任务事务分离。

**Tech Stack:** Spring Boot / MyBatis-Plus / Redis / OSS / JUnit 5 / Mockito / H2。
