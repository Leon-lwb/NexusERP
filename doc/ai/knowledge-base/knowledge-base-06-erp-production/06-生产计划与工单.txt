# 生产计划与工单

生产计划将销售订单需求转化为可执行的生产任务，通过工单（Work Order）驱动车间执行、物料领用、报工录入和质量检验。本章档描述 MRP 运算逻辑、生产计划排程规则、工单生命周期及报工机制。

## 一、计划层级

NexusERP 生产计划分为三级：

1. 主生产计划（MPS）：按月滚动，以成品 SKU 为单位汇总需求，确定每月各成品的计划产量
2. 物料需求计划（MRP）：基于 MPS 和 BOM 展开，计算各层级物料的毛需求、净需求、计划订单
3. 车间作业计划：将 MRP 的工厂订单（ Planned Order ）转化为车间工单，按车间/产线排产

计划编制周期：
- MPS：每月 25 日滚动编制下月计划
- MRP：每周一运行一次，触发物料需求
- 车间作业计划：每日下午 5 点运行，排定次日工单

## 二、MRP 运算逻辑

MRP 运算的核心逻辑：

净需求 = 毛需求 + 安全库存 - 现有库存 - 在途量 +  allocations（已预留量）

运算参数：
- 提前期（LT）：物料采购提前期或工序加工时间
- 批量规则：按批（Fixed Lot）、按需（Lot-for-Lot）、经济批量（EOQ）
- 损耗率：生产工序按 BOM 中设定的损耗率增加需求
- 安全库存：成品按 20% MPS 计划量设置，原材料按 15% 设置

MRP 运算结果输出 4 类建议：
- 采购建议：原材料不足时生成采购申请单草稿
- 生产建议：成品能力不足时生成生产计划草稿
- 调拨建议：跨仓库存不平衡时生成调拨建议
- 呆滞预警：库存周转超 90 天的物料标红

## 三、工单编码与类型

工单编码规则：WO-{年份}-{流水号}

工单类型分为：
- 正常工单：按 SO 或生产计划生成的量产工单
- 返工工单：针对质量不合格品的返工任务，关联原工单号
- 试产工单：新产品或新工艺的试生产任务，不计入产能考核
- 维修工单：成品售后维修任务，由售后部门发起

## 四、工单生命周期

工单状态流转：

待排产 → 已排产 → 开工中 → 已完工 → 已报工 → 已入库 → 已关闭
           ↓         ↓
        已暂停     已取消

各状态说明：

待排产：MRP 运算生成的工厂订单，尚未分配到具体车间和产线。
已排产：车间计划员将工单分配到具体产线，排定开工时间。
开工中：车间开始执行，工人可领料、报工。
已完工：工序全部完成，等待质量检验。
已报工：检验合格，工人已完成报工录入。
已入库：成品已入库 WH-F01，系统自动增加成品库存。
已关闭：财务已核算工单成本，归档。

已暂停：因物料短缺、设备故障等原因暂停，恢复后从断点工序继续。
已取消：因订单取消或计划调整而终止，需走取消审批。

## 五、工单排产规则

排产优先级规则（按优先级从高到低）：

1. 战略客户订单（AAA 级客户）优先排产
2. 加急订单（经总监特批）优先排产
3. 按 SO 下单时间先后排序
4. 同一客户订单合并排产，减少换线
5. 同系列产品（使用相同 BOM）集中排产

排产约束：
- 单条产线日产能上限：NX-200A 为 500 台/班，NX-T100 为 800 台/班，NX-G200 为 300 台/班
- 换线时间：不同产品切换需 30 分钟换线时间（已包含在产能规划中）
- 物料齐套检查：排产前系统自动检查该工单所有物料的可用库存，缺料 ≥ 3 项则延迟排产
- 设备可用性：关联设备（SMT 线、测试设备）需处于可用状态

## 六、物料领料

领料触发：工单状态变为"已排产"后，系统自动生成领料单，车间计划员可执行领料。

领料流程：
1. 车间计划员确认领料单
2. 仓库按领料单拣货，按库位指引出库
3. 工人签收后系统扣减原材料库存
4. 工单状态变为"开工中"，工人可开始生产

超领与补领：
- 超领率 ≤ 5%：系统自动允许，无需审批
- 超领率 > 5%：需车间主管审批
- 补领：工单执行中物料不足，发起补领申请，审批后仓库补发

退料：完工后剩余物料需退回仓库，退料单经车间主管审批后执行。

## 七、报工与计件

报工规则：
- 按工序报工：每个工序完工后，操作员录入实际工时、合格数量、不良数量
- 报工精度：工时精确到 0.1 小时（6 分钟）
- 不良品处理：不良品需录入不良原因代码（如：焊接不良、元件极性反、测试 FAIL）
- 工序流转：当前工序报工合格后，工单自动流转到下一工序

计件工资计算：
- 合格品数量 × 工序单价 = 该工序计件工资
- 工序单价参考标准工时设定，随熟练度调整
- 月度统计个人计件工资，作为绩效工资组成部分

工时报工：非计件工序（如设备调试、换线）按实际工时录入，用于产能分析。

## 八、完工入库

完工条件：
- 所有工序均已报工合格
- IQC 终检合格（成品抽检方案：AQL 1.0）
- 包装检验合格（标签、说明书、配件齐全）

入库流程：
1. IQC 终检合格后，在系统中录入完工检验报告
2. 系统自动生成成品入库单，物料从车间虚拟仓转入 WH-F01
3. 入库数量 = 合格品数量
4. 不良品单独入库 WH-E，关联维修工单或报废流程
5. 入库完成后，工单状态变为"已入库"，触发财务成本核算

成本核算：工单完工后，系统自动归集该工单的直接材料成本（BOM 用量 × 标准成本）、直接人工成本（计件工资）、制造费用（按工时分摊），输出工单成本报表。
