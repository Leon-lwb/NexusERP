# 生产与质量作业规范

文件编号：OPS-PRD-QC-001  
修订日期：2026-10-08  
适用范围：生产工单、MES 加工报工、质量处理与生产入库。实际流程以有效工艺路线和质量规则为准。

## 1. 工单与生产准备

生产工单应有可核对的计划或来源、产品、计量单位、计划数量与日期。生产准备核对有效 BOM、工艺路线、车间/工位、产能与物料需求；组件需求数量不能当作成品工单数量。来源计划和 MRP 的物料需求必须属于同一业务范围。

工单下发后，应核对 ERP 和 MES 的工单关联与消息消费结果。已生成派工或 SN 不等于工序全部完成，也不等于检验合格、生产入库或销售发货。

## 2. 工位过站与报工

单件过站应核验 SN、工单、当前工序、前序完成状态、设备与工位归属以及质量扣押。禁止跳工序、错误工位 PASS 或对同一单件重复写入 PASS。并发报工和离线重放均应遵守相同业务校验与幂等规则。

报工数量应区分合格、不合格和实际完成量。软件报工成功不能替代实际加工、检验或仓库入库。跨模块状态回写应核对原业务消息及累计数量，未知结果不能盲目重放创建单据。

## 3. 质量处理

来料检验、过程检验和出货检验应关联实际来源单据、批次或 SN，保留检验结果与处置依据。质量扣押中的物料或单件不得绕过放行规则继续流转。

NCR 应记录不符合项、责任与处置；返工应关联原缺陷和返工路线。返工完成后需要相应的复检及入库核对，不能直接将原不合格记录改写成未发生。不合格、退料、报废和让步接收按有效权限与审批规则处理。

## 4. 生产入库与发货

生产入库须关联有效来源工单或报工、合格数量、批次/SN 和实际仓库储位，保留库存流水。销售发货应核对销售来源、客户、可用库存和出货检验要求。

追溯查询应能连接来源采购批次、领料、工单、工序记录、质量记录、生产入库及销售发货；无法核对的环节应明确标注，不用已生成 SN 数量替代完整追溯证据。
