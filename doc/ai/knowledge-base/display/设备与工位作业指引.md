# 设备与工位作业指引

文件编号：OPS-EQ-ST-001  
修订日期：2026-10-08  
适用范围：设备采集、IoT 告警、MES 安灯、工位作业与运行记录核对。

## 1. 设备身份与采集来源

设备接入应验证凭证、租户、设备和授权主题归属。错误凭证、越权主题、重复消息和断线重连需要保留可核对结果。原始 MQTT 元信息、采集时间、设备标识与处理结果应能关联，不能只看页面曲线就判定来源可信。

软件回放与真实传感器数据必须区分。人工生成的温度值可以验证软件链路，但不能替代现场传感器实测或现场设备验收。

## 2. 告警与安灯

设备属性越限后，应按有效告警规则识别异常并关联设备。IoT 告警到 MES 安灯需要核对告警、通知、安灯记录及关闭结果。恢复正常与安灯关闭是不同业务事实，应分别保留事件与时间，不用一个状态覆盖全过程。

告警阈值及单位以设备产品配置和有效规则为准，知识资料或模型不得自行编造设备测量值、阈值和持续时间。

## 3. 工位作业

作业前核对工位、设备、授权操作员、有效工单与工序，以及所需 SOP。上料应关联正确物料、批次和来源，不得将未知物料、单位或库存来源视作有效输入。

工位写入口应与查询预检执行同样的前序、质量扣押和重复过站规则。设备通道的密钥、租户和幂等边界不能因离线重放而被绕过。

## 4. 运行与归档核对

采集归档应核对 IoT 历史记录、MES 采集点映射、归档记录和时间范围。定时任务配置存在不等于任务实际执行；须有本次执行记录或可核对的归档结果。

设备离线、心跳异常与数据缺失应明确呈现，不用缺失记录冒充正常零值。无法证明来源的采集结果，应作为未认证数据处理。
