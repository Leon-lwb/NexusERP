# 采购与库存作业规范

文件编号：OPS-PU-WM-001  
修订日期：2026-10-08  
适用范围：采购申请、采购订单、到货、检验、收货与库存业务。业务参数以系统已维护且可核实的物料、供应条款和来源单据为准。

## 1. 采购申请的来源核对

创建采购申请前，应核对物料、基本计量单位、需求来源与需求日期。MRP 来源必须关联实际需求行，不得把其他计划的数量挪用为当前工单的需求。库存必须能追溯到仓库、库区、储位和库存流水，预留、冻结及已被采购占用的数量应按来源核对。

没有库存记录不等于可靠库存为零。没有计量单位、换算版本、包装规则或 MOQ 单位时，应暂停数量认证，不得自行补成“件”。不同物料、不同单位的缺口不能直接相加成为采购总件数。

## 2. 数量与采购占用

申请数量以同一基本单位下可认证的剩余需求为依据。采购包装和最小起订量只有在换算、单位与供应条款可信时才能应用；小数需求不得未经规则核对擅自取整。人工、AI 与低库存申请均应经过统一额度与落账约束。

写入采购申请时，物料额度校验、需求占用和业务单据必须保持一致。重复执行同一请求，应回读既有结果，不重复创建单据。执行结果未知时，先回查原请求与单据，不能盲目再次提交。

## 3. 到货、检验与收货

采购订单到货后，核对来源订单、供应商、物料、批次和数量。需要来料检验的物料，应按检验结论处理；未经合格放行的数量不得作为可用库存。收货入库应记录实际仓库、储位、批次与实收数量，不能用计划数量替代实收。

部分收货、取消、关闭和采购退货，应核对订单累计数量、库存流水与采购占用状态。不能因为单据被关闭就无条件释放全部需求占用，也不能将退货等同于原收货未发生。

## 4. 领料与对账

生产领料应关联有效工单和物料需求，实际发料须有确定的仓库、储位、批次及实发数量。多批次发料时，应逐条保留库存批次来源，不能将一个批次编号套用到所有库存行。

领料单处于 CREATED 或实发数量为零时，不能宣称完成出库。对账至少核对采购申请与订单、到货和检验、收货与库存流水、领料与实际耗用、占用释放与业务事件。页面状态、软件完成标记和消息发出都不能单独证明实际库存闭合。
