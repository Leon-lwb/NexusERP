# 销售订单流程

销售订单（Sales Order，简称 SO）是销售部门向客户发出的销售确认单据，规定了交付产品的名称、规格、数量、单价、交期及交付方式。SO 从创建到关闭需经过报价、审批、生产/备货、发货、开票、回款全流程。

## 一、销售订单编码规则

SO 编码规则：SO-{年份}-{流水号}

示例：SO-2024-0001 表示 2024 年第 1 张销售订单。

## 三、SO 生命周期与状态流转

SO 的状态节点如下：

报价单 → 待审核 → 已确认 → 备货中 → 已发货 → 已完成 → 已关闭
     ↓        ↓
   已作废   已取消

各状态说明：

报价单：销售员根据客户询价生成报价，未形成正式订单。可修改、可删除。
待审核：已提交正式订单，等待销售经理审批。
已确认：审批通过，等待生产/备货。
备货中：生产计划已排产或仓库正在拣货。
已发货：货物已交付物流/客户签收。
已完成：客户已签收确认，等待开票。
已关闭：财务已完成收款，订单归档。

已作废：报价单被废弃，不影响任何业务数据。
已取消：正式订单被取消，需走取消审批。已备货部分需走退货入库。

## 四、SO 创建规则

SO 的创建遵循以下业务规则：

1. 报价依据：SO 必须由正式报价单转化而来，不允许直接创建空白 SO。
2. 客户校验：客户必须在客户档案中处于"启用"状态，且信用等级不为 C 级（C 级需全额预付款特批）。
3. 价格校验：SO 单价不得低于系统设定的最低售价。最低售价 = 标准成本 × 1.3。低于此值需销售总监特批。
4. 库存校验：系统自动检查成品仓（WH-F01）可用库存。可用库存 ≥ SO 数量则直接备货；否则自动触发生产计划排产。
5. 交期校验：标准交期规则如下：
   - 现货：客户下单后 2 个工作日内发货
   - 小批量定制（≤ 100 台）：7–10 个工作日
   - 大批量定制（> 100 台）：15–20 个工作日
   - 交期需经生产部门确认后方可写入 SO
6. 分批发货：单张 SO 允许最多分 3 批发货，每批需在发货单中注明。
7. 合同约束：与 AAA 级战略客户签订年度框架合同，SO 须在合同有效期内且不超过合同余额。

## 五、发货与物流

发货流程：
1. 仓库收到 SO 发货指令后，从 WH-F01 拣货、打包、称重
2. 打印装箱单与快递面单（对接顺丰/京东物流 API）
3. 物流取件后在系统中录入运单号
4. 客户签收后，物流系统回传签收状态，SO 自动变为"已完成"

物流规则：
- 省内：默认顺丰次日达，运费供应商承担
- 省外：默认京东物流，运费供应商承担
- 加急：顺丰特快，运费差额客户承担
- 自提：客户凭授权书到厂自提，无需物流

## 六、退货流程

客户退货触发条件：
- 产品质量问题（7 天内发现）
- 规格型号与订单不符
- 交付数量超出订单 ±5%

退货流程：
1. 客户发起退货申请，销售员在系统中创建退货单（SR）
2. 质量部对退回产品进行检验，判定为合格的重新入库，不合格的进入 WH-E
3. 入库完成后，财务计算退款金额
4. 退款方式：同客户结算方式（原路退回或抵扣下期货款）
5. 退货单状态：待退货 → 已退货 → 已退款

退货时效：客户需在签收后 15 天内发起退货申请，逾期不受理（质量担保期例外：12 个月内质量问题可申请维修或换货）。

## 七、开票与回款

开票规则：
- SO 状态为"已完成"后，财务可发起开票
- 发票类型：增值税专用发票（税率 13%）
- 开票信息须与客户档案中的税务信息一致
- 每月 5 日前统一开具上月已完成订单的发票

回款管理：
- 财务在系统中记录每笔回款，自动匹配对应 SO 或预付款
- 超期未回款自动生成催款函，抄送销售经理
- 超期 30 天以上暂停该客户下单权限
- 超期 60 天以上启动法务催收流程

年度对账：每年 1 月 15 日前完成上年度全部客户对账单，双方确认盖章后归档。
