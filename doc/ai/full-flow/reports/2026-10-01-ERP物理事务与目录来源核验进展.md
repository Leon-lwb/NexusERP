## 3. 实际 ERP 专属物理事务入口

新增内部 `PuRequirementErpTransactionExecutor`，从命名 MyBatis 工厂解析已核显式 ERP 物理池，用调用私有的 Spring 本地事务管理器起事务，只有该真实连接持有者可以提供路由别名。

- 前置拒绝已有事务／同步／资源、跨库 XID 和错误租户；不是在任意外部事务上补绑来取得资格。
- 核验实际 MyBatis 参与、同步凭据及同一连接；回调异常、rollback-only、身份／资源漂移均失败。普通底层诊断固定脱敏，模拟 VM 致命错误保持原对象传播；即使回滚／收尾失败也不能被框架新异常覆盖，但不据此认定回滚成功。
- 在提交准备和回调异常／待回滚出口，通过公共同步注册 API 只包裹本次已核原生 MyBatis 同步，保留其他同步引用及同序相对顺序，透明委托全部公共生命周期（含 savepoint）。归属观察紧邻原生清理，覆盖 beforeCommit 及同序 beforeCompletion 的晚到替换；真正拒绝位于 JDBC commit 之前的可传播检查，不依赖 Spring 可能吞掉的清理异常。回滚出口只读工厂／holder／明确会话配置用于清理观察，不读取或借用会话连接，不授业务资格。
- 异常收尾仅保留或向空键恢复同一个外来 factory 引用，已有不同引用不覆盖；不宣称框架从未临时解绑，也不把恢复资源作为成功或资格。
- 只支持精确已核 Hikari 及标准 Item/P6DataSource/同一 Hikari 链；未知包装、子类、错池、Seata 及 ERP 与其他注册共享池拒绝。身份快照涵盖注册、实际委托及物理池。
- 专属入口直取 Hikari，**不经过该连接级 Spy 日志路径**；不更改全局 Spy 注册、开关或安全审计。本内部能力尚未接控制器或统一采购写入口，不是通用回调沙箱或跨库 ACID 保证。

## 4. 可信采购目录的独立只读来源

新增 `ErpPurchaseCatalogSourceReader` 和固定只读 Mapper。仅接租户、物料、供应商身份，从真实 ERP 库读取物料、明确供应关系、数据库时钟及必要单位；不接外部时间、verified 布尔或外部条款事实。

- 通过实际服务代理进入独立只读、REPEATABLE READ 事务；检查本租户、来源身份与状态、唯一供应关系、新条款版本／生效／到期／核验时间、数量精度和范围。
- 单位必须同维度、明确共同主单位、自映射恒等和一层精确比例；未知链、NULL、未来核验、失效来源及不可精确换算拒绝。快照及版本映射不可变，不保留可变 Date 别名。
- 字段级二值 handler 只接受 0/1，NULL 保留未知，其余原始数值拒绝；字段级日期解码经实际 JDBC 合成 SELECT 验证，不改全局 Boolean 或日期映射。
- 本新片段仅支持 Asia/Shanghai 墙上 DATETIME 存储，连接 session 必须精确 `+08:00`；SYSTEM、UTC 和其他偏移在目录查询前拒绝。**该支持合同不替用户确认历史存储口径，不回填 NULL 或修改用户／global 时区。**
- Mapper 查询中的任何 RuntimeException，包括 ServiceException，均替换为新的固定诊断，不复制原 message、code、detail、cause 或 suppressed；查询外受控拒绝保持诊断，Error 原样传播。
- 该目录合格仅是目录事实，**不等于 quantityEligible**；后续执行必须在完整统一 ERP 写事务重新认证所有来源、库存、额度和版本。本片段不放行采购。

最终定向 GREEN：203 个实际用例全通过、0 跳过；独立规格及质量复核通过。
