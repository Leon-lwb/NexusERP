## 1. 身份、版本与传输

协议标识为 `nexus-engineering/1`。服务端拒绝未知主版本；设备上报 `connectorVersion`、`cliVersion`、`editorVersion`、实际能力集合和模板摘要。CLI 可运行不证明编辑器版本和每个导出 API 可用。4.1.60基线使用连接器自有STDIO MCP桥接官方CLI/API，上报 `transportMode=CLI_COMPAT` 及 `NATIVE_MCP_UNSUPPORTED` 诊断；不把CLI帮助中的MCP选项当作原生MCP握手成功。

浏览器接口使用现有 Sa-Token 与租户机制。连接器接口使用 `X-Nexus-Device-Token`，值只在请求头出现；服务端从凭证还原租户、用户和设备，不从请求正文接受这些身份。设备认证后的数据访问放在 `TenantHelper.dynamic` 中；禁止扩大现有 `security.excludes`。

首期是 HTTPS 短轮询；本地开发可以使用显式配置的环回 HTTP。生产 URL 不允许自动降级或跟随到其他主机。设备不开放 HTTP 入站端口。服务端错误响应携带traceId，任务按taskId/requestId关联；连接器只记录安全中文摘要，日志不包含凭证、文件正文或AI API Key。

所有雪花 ID 使用十进制字符串；租户 ID 保留文本前导零；模板尺寸按元数据约束校验十进制值，BOM数量由归一化报告提供。时间是 UTC ISO-8601，网页按用户时区显示。

## 2. 配对与撤销

浏览器创建配对码时固定当前租户、用户和允许的能力；配对码为 256 位随机值，5 分钟失效。Redis 仅保存摘要和用途，兑换采用原子消费，同码并发只能成功一次。

连接器兑换成功后取得 `deviceId`、15 分钟访问凭证和 7 天刷新凭证；数据库仅保存摘要、凭证代数和到期时间。刷新凭证单次使用并旋转；刷新响应丢失时要求重新配对，不复活旧凭证。连接器使用 Windows DPAPI CurrentUser 加密刷新凭证，访问凭证仅驻留内存。

每次领取、续约、回报、上传、读取均复核设备状态、当前用户状态、租户状态和所需权限。system 身份适配器返回密码/认证状态的内部摘要；与配对时摘要不一致即撤销凭证。原始密码散列和内部摘要不进入设备响应、AI 工具结果和日志。解绑后立即拒绝现有任务回调；旧租约不得用于再上传。

## 3. 接口清单

所有路径均为后端路径，不带前端开发代理前缀。普通结果使用现有 `R<T>` 包装；任务列表使用现有分页包装；`content` 返回文件流。文中的 401/403/409/413/422 是 HTTP 状态，连接器不能只检查 `R.code` 而忽略状态码。

| 方法与路径 | 调用者 | 行为 |
|---|---|---|
| `POST /ai/engineering/devices/pairing-code` | 浏览器 | 生成一次性配对码 |
| `GET /ai/engineering/devices` | 浏览器 | 当前用户设备与实际能力 |
| `DELETE /ai/engineering/devices/{deviceId}` | 浏览器 | 解绑、撤销凭证、阻止后续回调 |
| `GET /ai/engineering/templates` | 浏览器/AI | 当前允许的模板、版本、摘要及参数约束 |
| `POST /ai/engineering/tasks` | 浏览器/AI | 创建受控动作任务，提交端生成幂等键 |
| `GET /ai/engineering/tasks` | 浏览器 | 当前用户分页任务；允许按会话过滤 |
| `GET /ai/engineering/tasks/{taskId}` | 浏览器/AI | 状态、阶段、错误、清单摘要 |
| `POST /ai/engineering/tasks/{taskId}/cancel` | 浏览器/AI | 设置取消请求或直接取消未领取任务 |
| `GET /ai/engineering/tasks/{taskId}/manifest` | 浏览器 | 返回已确认且有权读取的产物清单 |
| `GET /ai/engineering/artifacts/{artifactId}/content` | 浏览器 | 按产物权限代理 PNG/OBJ/MTL/纹理或下载源工程 |
| `POST /ai/engineering/connector/pair` | 连接器 | 兑换配对码；只开放此单一路径用于配对 |
| `POST /ai/engineering/connector/refresh` | 连接器 | 验证并旋转刷新凭证 |
| `POST /ai/engineering/connector/unpair` | 连接器 | 撤销当前设备及凭证，清理本机加密身份 |
| `GET /ai/engineering/connector/tasks/{taskId}` | 连接器 | 认证后恢复当前尝试、修订号、取消和已记录事件 |
| `GET /ai/engineering/connector/tasks/{taskId}/manifest` | 连接器 | 上传丢响应核对本设备任务已确认文件 |
| `GET /ai/engineering/artifacts/{artifactId}/report` | 浏览器 | 读取有界、字段归一化的BOM或DRC，原始文件由content下载 |
| `POST /ai/engineering/connector/heartbeat` | 连接器 | 上报能力与可用状态，不接受归属身份变更 |
| `POST /ai/engineering/connector/claim` | 连接器 | 领取分配给自己的任务；空闲返回 data=null |
| `POST /ai/engineering/connector/tasks/{taskId}/renew` | 连接器 | 延长当前领取租约 |
| `POST /ai/engineering/connector/tasks/{taskId}/events` | 连接器 | 提交当前阶段与递增步骤序号 |
| `POST /ai/engineering/connector/tasks/{taskId}/upload-ticket` | 连接器 | 申请绑定类型、大小、哈希和本次尝试的短期票据 |
| `POST /ai/engineering/connector/tasks/{taskId}/artifacts` | 连接器 | multipart 字段 `file`，上传且确认单个产物 |
| `POST /ai/engineering/connector/tasks/{taskId}/complete` | 连接器 | 服务端核对清单与检查结果后计算终态 |

权限采用 `ai:engineering:device`、`ai:engineering:task`、`ai:engineering:query`、`ai:engineering:download`。设备最小能力由配对身份与当前权限共同决定；用户失去权限后，设备不能继续使用先前授权。任务、产物默认仅创建者可见，租户管理员身份不自动授予全部文件访问。

## 4. 创建任务与 AI 工具

动作枚举：`CHECK_CONNECTION`、`OPEN_PROJECT`、`CREATE_PCB_DRAFT`、`EXPORT_ARTIFACTS`、`RUN_DRC`、`SUBMIT_DRAFT`。生成任务默认完整执行创建、检查、导出和归档；单步动作必须引用同一用户的原任务，不传入本地路径。

`EngineeringTaskCommand` 字段：`deviceId`、`action`、`idempotencyKey`、`sessionId`、`templateId`、`templateVersion`、`templateSha256`、`parentTaskId`、`parameters`。身份由服务端创建的 `EngineeringActor` 提供；原始用户请求另作有界说明，不能执行。

首期 `parameters` 只允许板宽、板高、板层和模板声明的可选模块。必填的电气参数缺失时返回 `NEEDS_INPUT` 工具结果，不创建不明设计任务。工作目录、软件路径、任意代码、任意 URL、器件库脚本均不作为参数开放。

```json
{
  "protocolVersion": "nexus-engineering/1",
  "deviceId": "2000000000000000001",
  "action": "CREATE_PCB_DRAFT",
  "idempotencyKey": "6b61df2d-e7f0-4dd2-8928-3cf4a3761fb8:create_pcb_draft",
  "templateId": "temperature-humidity-demo",
  "templateVersion": "1.0.0",
  "templateSha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "parameters": {"boardWidthMm": "50.0", "boardHeightMm": "35.0", "layers": 2}
}
```

相同 `(tenantId, userId, idempotencyKey)` 且规范化请求 SHA-256 相同，返回原任务；键相同但摘要不同返回 409 `IDEMPOTENCY_CONFLICT`。不同用户和租户不能碰撞复用。AI 的键由服务端用本次 `engineeringRequestId + action` 产生，模型无权自定用户身份和幂等命名空间。

## 5. 领取、阶段与状态

领取响应包含：`taskId`、`action`、`attempt`、`revision`、`leaseToken`、`leaseExpiresAt`、`deadlineAt`、模板引用和结构化参数。租约令牌是不可猜随机值，只保存摘要。设备校验模板摘要后在专属目录执行。

```text
CREATED -> WAITING_DEVICE -> RUNNING -> SUCCEEDED
                                  -> PARTIAL_SUCCESS
                                  -> FAILED
                                  -> CANCELED
WAITING_DEVICE -> CANCELED / EXPIRED
CREATED       -> CANCELED / FAILED
```

终态不再转移。未领取任务默认 15 分钟过期；运行默认 20 分钟截止。每台设备同一时间只允许一个任务，数据库对设备忙碌标记与任务领取在同一短事务内更新。服务端不在数据库事务或全局锁内等待 MCP、网络或上传。

固定阶段：`CHECKING`、`PREPARING`、`GENERATING`、`CHECKING_DRC`、`EXPORTING`、`UPLOADING`、`FINALIZING`。`sequence` 递增，用于防重复阶段记录；与服务端 `revision` 分开。阶段事件最多 64 条，每条消息最多 2 KiB，超出以错误类别摘要保存。

回调携带 `attempt`、`leaseToken`、`expectedRevision`、`sequence`。旧尝试、旧令牌、租约过期、终态或已解绑返回 409/403，不能覆盖当前记录。相同序号和同摘要重试返回原回执，不二次推进；相同序号不同摘要返回冲突。

领取默认每 3 秒轮询；心跳每 15 秒；租约有效 90 秒，每 30 秒续约。运行任务收到取消请求后在步骤间停止，先上报确认再由服务端进入 `CANCELED`；不关闭用户原有编辑器会话。

离线或响应丢失不等于任务未执行。连接器使用本地 journal 保存“动作已开始/完成”的步骤。租约仍有效时允许以同任务同尝试恢复查询和上传；租约过期则标记 `FAILED/EXECUTION_UNCERTAIN`，保留产物和本地工程供人工检查。不会自动重做可能已写入编辑器的步骤。

连接器与本机MCP之间使用带确认的 `nexus/stage` 请求，字段为taskId、attempt、stage；父进程取得服务端事件回执后才返回 `acknowledged=true`。超时、取消或鉴权失败即拒绝确认并停止后续设计副作用。文件传输不占用续约控制队列，慢上传期间继续续约；HTTP请求同时服从调用者取消与请求超时。409先读取设备任务详情，再按最新revision处理取消或同尝试恢复，不能盲写覆盖。

可恢复状态使用DPAPI保护并绑定Nexus地址，包含attempt、lease、revision、事件sequence、待确认事件原文和已确认执行的上传元数据，不保存BOM/DRC报告正文。重启先认证读取任务，再恢复查询/回报/上传；执行阶段未确认即按 `EXECUTION_UNCERTAIN` 处理，不重放设计。工作区journal不保存租约或设备凭证。

服务端每 30 秒扫描等待超期、租约和运行截止，用 CAS 更新状态。维护扫描带集群互斥或 CAS 竞争，显式设置租户上下文并清理；只修改工程三表和未确认的临时对象。

## 6. 产物、清单与限制

产物先申请票据，再上传；`X-Nexus-Upload-Ticket` 与设备访问凭证同时验证。票据绑定 `taskId/attempt/deviceId/artifactType/relativePath/sha256/size`，5 分钟有效。服务端暂存文件流，核对真实 SHA-256、大小、类型和任务状态后，才写私有 OSS 和产物记录。

上传请求成功但响应丢失，连接器通过 manifest 的 `(taskId, attempt, artifactType, relativePath, sha256)` 确认已有记录；同键不同内容拒绝。临时失败重新申请票据并整文件重传；首期无分片协议。S3 ETag 不替代 SHA-256。

限制：每产物 100 MiB；每任务 300 MiB、64 个文件；PNG 解码像素上限 32M；OBJ 顶点上限 2M；manifest 128 KiB；BOM 10,000 行；DRC 10,000 条，额外条目以截断标记显示。任务累计配额在数据库事务内预留，失败归还，不因并发上传绕过。

类型：`PCB_SOURCE`、`PCB_PREVIEW_2D`、`PCB_BOM`、`PCB_NETLIST`、`PCB_DRC_REPORT`、`PCB_MODEL_OBJ`、`PCB_MODEL_MTL`、`PCB_MODEL_TEXTURE`。原始文件名供显示，存储键由服务端生成。PNG 为首期唯一直接展示的二维格式；SVG 可归档，不使用未净化 SVG 内联渲染。

示例中的产物 ID 是合成数据，`relativePath` 只能是当前产物组内的相对路径：

```json
{
  "protocolVersion": "nexus-engineering/1",
  "taskId": "2000000000000000002",
  "revision": 7,
  "state": "PARTIAL_SUCCESS",
  "drc": {"status": "VIOLATIONS", "errorCount": 2, "warningCount": 1},
  "artifacts": [
    {"artifactId": "2000000000000000006", "type": "PCB_SOURCE", "relativePath": "source/project.zip", "size": 16384},
    {"artifactId": "2000000000000000007", "type": "PCB_BOM", "relativePath": "reports/bom.json", "size": 1024},
    {"artifactId": "2000000000000000008", "type": "PCB_DRC_REPORT", "relativePath": "reports/drc.json", "size": 1024},
    {"artifactId": "2000000000000000003", "type": "PCB_PREVIEW_2D", "relativePath": "preview/top.png", "size": 4096},
    {"artifactId": "2000000000000000004", "type": "PCB_MODEL_OBJ", "groupId": "model-1", "relativePath": "model/board.obj", "size": 8192},
    {"artifactId": "2000000000000000005", "type": "PCB_MODEL_MTL", "groupId": "model-1", "relativePath": "model/board.mtl", "size": 512}
  ],
  "missingTypes": ["PCB_NETLIST"],
  "canManufacture": false
}
```

实际 manifest 包含每产物的完整 64 位十六进制 `sha256` 和内容接口路径；绝不包含磁盘绝对路径、长期凭证或永久公共 URL。`canManufacture` 在首期恒为 false。

完成规则：服务端从已确认产物计算结果，连接器不能自报成功。生成动作至少源工程、PNG、BOM、DRC、OBJ 齐备且 DRC `PASS` 才为 `SUCCEEDED`；缺少非阻断产物、DRC 报违规或 `UNAVAILABLE` 为 `PARTIAL_SUCCESS`；未生成源工程或没有任何可预览产物为 `FAILED`。单步动作使用动作自己的必需产物集合，不要求 `CHECK_CONNECTION` 生成 OBJ。

DRC 状态区分 `PASS`、`VIOLATIONS`、`UNAVAILABLE`、`NOT_RUN`，不以空报告代表通过。BOM JSON 规范字段为 `designator`、`value`、`footprint`、`manufacturerPartNumber`、`supplierPartNumber`、`quantity`，缺值为 null；首期不自动写 ERP 物料。

## 7. OBJ 与路径

OBJ、MTL、纹理构成同一 `groupId`。连接器列出导出文件实际相对路径；服务端校验引用均为组内合法路径；本组材质未上传时在清单记录缺失，任务按部分成功收尾，前端以统一材质显示几何及警告。前端只从同任务清单生成 Blob URL，不尝试请求缺失引用。拒绝 `http:`、`https:`、`file:`、UNC、盘符、绝对路径、`..`、符号链接和 Windows junction 逃逸。MTL 的 `map_Kd` 等纹理引用只允许同组清单；本组纹理缺失时降级统一材质，不向任意URL取图。

无 MTL 时以统一材质显示几何，并标记“无材质”；OBJ 缺失或解析失败显示错误和下载入口，不伪造模型成功。前端切换任务时中止旧请求，释放 Blob URL、材质、纹理、Geometry、Controls、WebGLRenderer 和动画帧。

## 8. 错误与重试

| 错误码 | 行为 |
|---|---|
| `DEVICE_OFFLINE` / `EDITOR_UNAVAILABLE` | 返回实际状态或等待，不能宣称已创建 |
| `TEMPLATE_UNAVAILABLE` / `TEMPLATE_HASH_MISMATCH` | 停止执行，不下载任意来源模板 |
| `CAPABILITY_UNSUPPORTED` | 明确缺失的导出能力和适配版本 |
| `IDEMPOTENCY_CONFLICT` / `STALE_ATTEMPT` | 409，读取原任务，不能覆盖 |
| `LEASE_EXPIRED` / `EXECUTION_UNCERTAIN` | 停止写操作，保留工程供人工核对 |
| `UPLOAD_TOO_LARGE` / `UPLOAD_HASH_MISMATCH` | 拒绝且不登记可见产物 |
| `ARTIFACT_REFERENCE_INVALID` | 拒绝外部资源或缺失材质引用 |
| `OWNER_REVOKED` / `DEVICE_REVOKED` | 401/403，停止领取与上传，要求重新配对 |
| `EXPORT_FAILED` / `DRC_UNAVAILABLE` | 保留成功产物，按集合判定部分成功 |

网络重试最多 5 次，延迟 1/2/4/8/16 秒加抖动；当前429采用同一有界退避，所有请求尊重 `AbortSignal`；首期尚未解析 `Retry-After` 响应头。仅对幂等读取、同回执重试和上传确认使用重试，不自动重放设计写入。服务端错误另带对用户可读的中文摘要和traceId；连接器保留安全错误类别，不回显服务端正文。
