# 工业交付决策等待与 PC 详情体验设计

## 范围与原则

- 仅调整 ERP 后端和 `plus-ui` PC 页面；不触碰 App、演示数据库、审批语义、事实评分和 Golden 期望。
- LLM 节点等待默认 90 秒、保留现有最多两次尝试；模型 HTTP 读取超时 180 秒不动。失败仍以服务端模板摘要降级，未验证模型文本不能决定评分或动作。
- 进度是可证实的工作流阶段与已等待时间，不将模型推理时间伪装为可预测百分比；终态仅来自服务器。

## 后端模板与安全迁移

- 新增 `nexus.ai.flow.industrial-decision-llm-timeout-seconds`，默认 90、允许 30–120 秒；生成工业分析图时仅对 LLM 节点设置该值。
- `DecisionFlowDefinitionFactory` 能重建字节级一致的旧版 30 秒图。已存图仅在与当前可信生成图、旧版 30 秒图或已发布默认 90 秒图完全一致时迁移；其他结构/配置修改继续拒绝。更新通过现有租户、状态、版本和旧配置 CAS；无需手工 SQL。
- 工业执行图及非工业流程不改变。测试覆盖 30 秒旧图升级、同版不升级、篡改拒绝、配置边界和节点默认值。

## PC 进度与信息展示

- 详情页组合 `AI_FLOW_NODE_START/END` 的实例 ID、现有决策终态事件及每 5 秒状态查询；重连或错过事件时以服务端运行/时间线恢复。禁止其他运行 ID/实例的事件污染当前页面。
- 增加阶段面板，提供阶段名称、当前状态、已用时间、持续等待提示；运行中进度条为不确定态，模型节点说明等待时间无法预估，终态才显示完成或失败。SSE 不能替代轮询兜底，轮询不重复加载大证据列表。后台时间线查询只投影节点 ID、状态和时间，不加载可能达到兆字节的流程 input/output JSON。
- 将方案预览从原始 JSON `pre` 改为白名单字段表（工单/工序、资源、起止、工时、延期）；大型预览限量/分页；原始数据仅作为折叠只读审计视图。方案、动作、证据展示名称、可行性原因和业务语义；原审批确认及安全白名单继续生效。
- 防止把错误原文、未经验证的外链或任意 JSON HTML 直接插入 DOM；避免将 64 位雪花 ID 转成 JS number。

## 验证

- Java 单元测试先红后绿，并运行 AI/Flow 测试及 admin 编译打包。
- UI 对纯进度模型、事件隔离、结构化预览和异常值补测试，运行前端单测、类型检查、定向 ESLint 与生产构建。
- 不停止用户当前服务；上线后的真实 LLM 运行结果需重启后用新运行另行确认，旧运行保持原状态。
