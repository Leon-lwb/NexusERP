# 自研报表基础模板目录与筛选口径

更新日期：2026-10-17；实现分支：plus。此目录描述代码能力；不代表现有环境已创建模板或完成生产验收。

2026-10-17 增补：代码目录新增销售订单打印、采购收货单打印，完整权限下现支持16个固定数据集、19类基础模板。原14个数据集/17类模板与其历史定义保留；本轮未向现有数据库写入新增模板。

## 创建与保留规则

报表中心的“创建基础报表”按当前账号权限增量登记数据集并创建、发布缺少的模板。初始化需要同时具有 `report:dataset:manage`、`report:definition:add`、`report:definition:publish` 和对应业务权限。完整权限下共19类；字段权限不足时，不创建依赖受限金额的变体。按钮反馈的是本次可用基础报表数，不是本次新增数量。

同编码的已存在定义不会被覆盖、重新发布或恢复为可用状态，用户修改、修订号、下线与归档状态均保留。原14个provider契约没有变更；本轮新增两类使用新编码和版本一。所有基础模板使用schema1/engine1.0.0，不要求E2–E7新增表，也不添加报表物理表或自动执行数据库脚本。

## 业务选择与完整ID

数据集样例、草稿预览和正式运行共用业务选择器。可以输入名称、编码或完整ID检索；预填ID单独按值解析并显示“编码 · 名称”。仓库、物料、客户、供应商、采购/销售订单、送货单、MES工单、车间和来料检验单使用代码注册规则。物料编码型参数保持原有STRING语义和前导零。

ID全程使用字符串，不能以Number或科学计数法传入。候选按业务表的权限和组织范围读取，表名、字段、租户或身份不可由前端指定。没有授权绑定时仍可明确输入完整ID；此输入不会扩大实际取数权限。读取失败支持重试，原参数不被清空；对象不可见时仅提示名称不可用，不伪造候选。分页按原始消费进度结束，去重不会导致反复请求空页；搜索和名称回显分别隔离迟到响应，切换版本或卸载会取消未开始的防抖检索。

## 日期、数量与金额

库存流水默认按发生日期查询近六个月；工单、检验台账按创建日期查询近六个月，以保留没有计划时间或尚未检验的记录。界面提示“留空使用六个月前/今天”，实际日期由后端计算。销售/采购明细的可选订单日期不设隐含默认范围，按单号查历史单据时不会被六个月默认条件意外排除。原销售/采购执行契约的日期默认规则保留。

待发量=max(订购量-已发货量,0)，待收量=max(订购量-已收货量,0)；退货数量另列，不假定退货会重新打开发货/采购需求。作废的销售/采购订单和已取消销售明细不计入新增执行明细，工单台账保留取消记录供追踪。已知枚举显示中文，未知值保留原始编码。

DECIMAL和ID由服务端按精确类型输出，浏览器只格式化文本。金额只能按币种相加，数量必须按物料编码和单位相加。价格、库存余额流水和没有单位的IQC数量不能汇总；打印单据中的订单头金额不随明细重复求和。库存可用量逐行由服务端受限公式计算，首期引擎不直接汇总计算列。

## 权限与扩展边界

元数据保持master，ERP业务取数和候选走erp，MES工单/检验走mes。MES模板中的ERP参考对象通过具有各自权限的ERP候选查询解析，不跨数据库SQL联表。销售/采购明细的父子表联表固定包含tenant_id一致和子表del_flag正常；公共查询底座继续附加根实体的租户、删除和组织范围，财务字段额外收紧业务范围。

后续增加目录时使用新数据集编码或新契约版本，声明精确类型、默认列、固定参数、字段权限及汇总维度。若已发布，不能直接改写旧契约校验和或报表JSON；需要显式注册新版本，并通过设计器比较、升级和重新发布。新增业务筛选可复用JdbcReportLookupProvider的Rule，不接受运行时SQL片段。
