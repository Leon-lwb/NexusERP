## 开始使用

报表中心包含“报表管理”“数据集目录”“导出中心”。菜单、按钮、资源 ACL 和业务权限同时检查；有菜单不等于可以读取任意数据。管理员可点击“创建基础报表”，增量准备当前权限下最多19类模板，包含原17类及新增销售订单、采购收货单打印；详见[基础模板目录与筛选口径](报表基础模板目录与筛选口径.md)。已有同编码定义及其用户修改、下线/归档状态保持不变。单据模板可通过业务选择器填写相应单据 ID；采购订单、销售订单、送货单和采购收货单列表提供单张及多选批量入口。

数据集目录可注册代码内已安装的 provider 契约、查看字段与精确类型样例、启用/停用并管理 ACL。首期不提供用户填写 SQL、数据库连接串、脚本或外部 HTTP 数据源。

## 报表工作台界面

报表中心提供目录导航、名称/编码搜索、类型和发布状态筛选。顶部状态卡可直接过滤列表，数量仅统计接口返回的当前可见资源。列表和卡片共享相同条件；没有匹配结果时可点击“清空筛选”。手机宽度下目录选择位于筛选栏，有目录管理权限时可从页头新建目录。

“运行”和“设计”保留在每份报表旁；发布历史、复制为草稿、发布、下线、授权和归档收在“更多”菜单中。每项操作分别检查权限，复制仍同时要求源模板编辑权限与新增权限。交叉报表的“设计”进入专用交叉设计器。快捷入口只连接当前已注册的页面；尚未安装的扩展菜单不会产生无效跳转。

设计器按字段、画布和属性分区，字段搜索不会改动草稿。工具栏保留常用操作，校验及模板包操作收在“更多”；“专注编辑”扩大画布。小于1024px时字段和属性通过侧栏抽屉打开，纸张在画布容器内滚动。运行页分为“查询条件”和“运行结果”，载入、尚未运行和执行失败有独立反馈；修改参数仍使原运行失效，精确值和汇总结果由服务端提供。

数据集、查询、交叉报表、图片、批次、仪表盘、导出、版本、订阅和交付页面共用页头和中文状态。表单与弹窗适配窄屏；设计面板和仪表盘图表跟随深色主题。示例截图均为隔离合成数据，不能作为真实业务结果或生产验收依据。

## 菜单切换故障排查

菜单切换后页面空白、目标列表没有接口请求时，应先检查页面是否完成挂载。正式布局使用 `Transition mode="out-in"` 和 `KeepAlive`；路由页面必须最终渲染单个元素根节点。私有图片、受控查询、个人仪表盘、订阅和批次页面的授权弹窗已移入 `ReportPage` 内，避免并列根节点形成 Fragment，使离场过渡无法结束。此问题取决于菜单切换顺序，刷新会重建过渡状态，但不解决原结构问题。

`next()` 导航守卫弃用提示来自旧式守卫写法，不能单凭此提示判断空白原因。本次隔离回归未加载登录导航守卫，仍能在修复前复现空白及无目标请求；修复后按实际布局验证菜单切换和缓存恢复。未改动登录守卫或权限规则。

## 运行条件与导出兼容

采购订单打印、送货单打印和来料检验追溯等单据报表必须先选择关联单据，运行、预览和数据集样例会提示具体必填条件；可选的仓库、客户等条件允许留空。空白值使用模板默认值，模板未设置时继承固定数据集默认值，具体日期由服务端在执行时解析。

局域网HTTP访问可能没有crypto.randomUUID。当前导出和订阅手动执行会使用安全随机字节生成UUIDv4；如果安全随机能力也缺失，会给出明确提示。网络失败后的重试继续使用同一幂等键。相关修复及验证见[HTTP导出与空条件运行修复记录](../plans/2026-10-15-report-http-runtime-fixes-verification.md)。新增基础模板由管理员通过“创建基础报表”或明确授权的同一bootstrap服务按权限增量创建，不随部署自动写入数据库。2026-10-15已在本机ry-vue、租户000000补齐至14个数据集、17份已发布基础报表，原六份保持不变；其他环境仍需单独初始化，详见上述验证记录。

## 设计、发布和回滚

1. 在报表管理点击“新建报表”，选择数据集、唯一报表编码、标题和目录。已有编码、类型和目录固定；修改已有报表进入设计页面。
2. 按标签、绑定名或类型搜索字段，点击字段添加，也可聚焦后按 Enter / Space 或拖入明细区；拖动列排序。点选列设置标题、宽度、小数位、样式与受限公式，例如 `ROUND(quantity * unitPrice, 2)`；字段名来自所选数据集。
3. DOCUMENT 模板只有一个可增长明细区域。固定页眉与末页区域支持字段绑定、文本占位符、固定区内横纵合并；绑定例如 `单号：{{orderNo}}`、`第 {{page_number}} / {{page_count}} 页`。合并不能穿过明细区。
4. 设置纸张、边距、行高、续页列头及查询参数。日期默认可用 TODAY / MONTHS_AGO_6。SUM 等数值汇总必须保留契约要求的币种、物料或单位分区。
5. 执行校验和草稿样例预览；保存草稿后发布。草稿保存带 revision，其他人已修改时拒绝覆盖，需重新读取。定义文件可导出为自有 JSON，也可在“定义文件”页校验后应用；撤销/重做最多保留 50 个设计状态，编辑历史不进入 DSL。
6. 发布版本不可改写；发布历史可将当前指针回滚至旧版。下线立即阻止后续运行和交付，归档保留审计并隐藏资源。已有运行固定引用原发布版本，不随新版本更新。

草稿样例最多 200 行，不作为全量汇总。全量数据和分页结果在发布后使用固定快照核对。

## 契约版本、批量编辑和模板复用

设计器显示草稿固定的契约版本，字段面板不跟随目录新版本自动变化。“比较并升级契约”显示差异，确认后更新草稿版本与目标参数集合：移除旧参数、加入新参数，类型变化重置默认值，目标必填约束保留；未变化参数的标题与已有默认值保留。删除或变更的字段需要重新校验，发布不会改写旧版本。取消升级不影响原历史契约读取。

多选明细列可批量加粗、设置颜色/对齐及滑动调整列宽。复制/粘贴产生独立计算绑定，不覆盖原列；DOCUMENT 粘贴适配纸张宽度并扩展整行固定区域，无法满足最小列宽时明确拒绝。Ctrl/Cmd+S保存；Ctrl/Cmd+Z撤销，Ctrl/Cmd+Shift+Z或Ctrl/Cmd+Y重做。预览与编辑分栏展示，较窄窗口改为上下排列。

报表中心“复制”需要创建权限及源模板编辑权限，副本只生成草稿。设计器“导出模板包”需要源模板EDIT；包含定义、引擎、provider版本及依赖checksum，移除源datasetVersionId及ID类默认参数，不含ACL/快照/租户数据。导入选择本租户已授权的兼容契约，并输入新编码/标题；依赖或校验和不匹配会拒绝。导入关闭弹窗不会撤销已提交的服务端请求；再次打开是新会话，旧回包不会替新会话导航。升级后的契约与原包不一致时不能直接导入，应先映射同版本兼容契约或重新导出。

选择器按固定契约和声明参数安装，候选范围由各业务实体自己的权限决定，并再次检查租户、数据集和业务权限。没有额外目录管理权限的业务用户仍可按预览权限使用已授权选择器。可按名称、编码或完整ID搜索，预填ID回显业务名称；读取失败可重试且保留原参数。数据集目录的样例参数同样使用已授权选择器。ID以字符串传入，拒绝已舍入的Number；同一模板换单据参数时会丢弃旧运行，需重新运行。

## 运行、导出和资源授权

TABLE 默认实时分页，允许按当前可见可信字段排序；聚合公式与分组汇总需要快照。DOCUMENT 自动使用快照。每次运行绑定参数、发布版本、数据集契约和当前权限指纹。ID 和 DECIMAL 以字符串传输，浏览器不重算业务数值。

实时分页每次读取业务库，页面之间数据可能变化；从实时运行导出会建立新的固定快照并显示新的数据时间。快照预览、PDF 与样式 XLSX 共用服务器 RenderPlan；明细 XLSX 导出原始精确值，超过 Excel 数值精度的数字保留文本。普通字符串不会转成 Excel 公式。

首次快照排版固定服务器 RenderPlan 和测量字体。新计划格式2保存私有字体引用，同租户按实际字体checksum去重，计划引用和读取租约保护字体；格式1仍可读取内嵌字体。此后同一运行的预览、PDF 和样式 XLSX 读取该产物；服务重启或字体配置变化不会重新分行、分页。新运行可使用新的字体配置。保存的排版和字体随运行到期一起清理，完整性或版本校验失败时拒绝交付。明细 XLSX 可独立运行，不依赖排版字体。

导出中心显示个人任务、准备/快照/排版/写入阶段及已处理行数，支持取消和经鉴权下载。每轮最多3次自动尝试，可重试失败最多追加2轮手动重试；重复提交相同retryRound只生效一次。手动重试保留原任务、运行、幂等键与有效期，attempt持续增长。到期、撤权、下线、容量等永久错误不能重试；需要新数据时重新运行。导出需要同时获得报表和数据集的 EXPORT 授权，以及报表平台导出权限；仅有数据集 VIEW 授权不能导出。默认文件保留 24 小时；快照数据时间来自实际取得执行权的时点。任务执行及文件交付前重新读取账户/角色/资源 ACL；租户、业务范围或字段权限变化时拒绝旧快照，需重新运行。ACL 的 USER/ROLE/DEPT 主体 ID 必须属于当前租户。

## 容量和配置

| 项目                | 首期界限                                                                 |
| ------------------- | ------------------------------------------------------------------------ |
| 列数 / 公式         | 1–40 列；表达式深度、长度与总计算预算受限                                |
| 页面列表            | 每页最多 200 行                                                          |
| 交互快照 / 版式导出 | 最多 5,000 行；最多 200 页                                               |
| 明细 XLSX           | 最多 100,000 行；流式读取和写入                                          |
| 固定排版产物        | JSON 最多 32 MiB，字体副本最多 64 MiB；合并产物仍受文件限额约束          |
| 导出文件            | 默认 100 MiB（单对象）；写入过程即检查容量                               |
| 任务                | 默认每节点 4 worker、240 秒时限，租约 30 秒、5 秒续租，最多 3 次执行尝试 |
| 队列准入            | 用户/租户受锁保护；跨租户全局候选限额不作为严格集群 SLA                  |

应用配置前缀为 `nexus.report`，默认不需增加环境秘密：

```yaml
nexus:
    report:
        artifact-root: ./data/report
        font-path: /usr/share/fonts/wqy-zenhei/wqy-zenhei.ttc
        workers: 4
        retention-hours: 24
        task-seconds: 240
        max-artifact-bytes: 104857600
```

字体路径来自可信服务端配置，模板/API 不能指定文件路径。Windows 可自动使用系统 SimHei，生产 Alpine 镜像安装文泉驿 TrueType 中文字体。字体不复制到 Git。容器 Compose 将 `/docker/server/report` 挂载到应用私有目录，不能由 Nginx 公开这个目录。

默认存储是带节点标识的私有文件系统。新增 S3 适配允许不同节点使用相同逻辑 storageId；双JVM强杀及重启已在隔离MinIO验证，生产集群需按部署拓扑另验。过期清理失败会保留文件引用并重试；本地存储还会有界回收超过保留期、经数据库确认没有引用的孤立文件，以及进程中断留下的临时文件。

耗时指标为 `nexus.report.duration`，使用固定phase/outcome标签；阶段包括编译、取数、计算、快照、布局、序列化、导出及下载交付。指标标签不含租户、用户、参数或明细。SXSSF行缓存使用租户私有压缩临时文件，结束、取消、异常和到期按既有私有生命周期清理。

执行器由 `ReportEngineRegistry` 按schema+engine精确选择，当前正式支持schema 1/engine 1.0.0。通过 `nexus.report.disabled-engines` 显式停用特定引擎，旧发布引用该引擎时明确拒绝，不回退到当前默认。新引擎要作为代码内执行器注册，并保留旧定义和兼容回归。

## 后续扩展入口

- 业务数据接入：在业务模块实现 common-report 的 ReportDatasetProvider，显式声明契约版本、参数、字段权限、维度和读库；禁止从 JSON 拼接 SQL 标识符。
- 定义与计算：新语法用新的 schema/engine 版本，保留旧解析与执行版本，不改写已发布 JSON。
- 导出格式：实现独立 exporter，复用 RenderPlan 或 TypedValue；不引入另一套分页计算。
- 存储：替换 ReportArtifactStore，为私有对象存储实现流式读写、校验、删除和节点/存储身份契约。
- P1/P2：受控查询目录、交叉表、仪表盘、钻取、订阅、外部分享分别单独设计与验收，不能直接开放 SQL/脚本或复用后台登录令牌。

## E2 受控查询与版本

“受控查询”只接受批准的逻辑实体、关系、字段和参数，不能提交SQL、物理表名、URL或连接信息。首版目录在ERP代码内安装，目录版本和查询规划语义版本共同进入固定依赖。发布生成CQ数据集版本，可在设计器选择。聚合维度保留原值，敏感筛选和关联实体各自执行权限与范围校验；DATE统一按自然日处理。

查询执行源默认关闭；启用需单独配置SELECT-only账户并通过实际授权核验，不能复用ERP业务写账户。目录可查看不代表独立只读执行源已启用。规划语义升级需注册兼容版本或重新发布查询，旧范围指纹不能自动当作新规划结果。

## E3 交叉分析

“交叉报表”使用schema2/engine2并强制固定原始快照。可设置最多3个行维度、2个列维度、5个指标，支持SUM、COUNT、COUNT_ROWS、MIN、MAX、AVG、小计、分区总计和TopN其他桶。排名按未显示舍入的精确值比较，AVG从原始sum/count计算。单位和币种分区不会混算。

矩阵、明细XLSX、PDF和样式XLSX共用透视投影；每列和整行总计作为精确数据行输出。动态指标列最多200，结果最多20000单元格。点击服务端坐标钻取同一次原始快照，支持分页，不重查业务库。纸张宽度容不下当前交叉投影时，PDF/样式导出明确拒绝；后续横向分页另行建设。

## E4 私有图片、条码和批次

“私有打印图片”接受5MiB以内PNG/JPEG，解码前检查尺寸，最多4096像素边长和1000万像素，归一化后生成不可变私有图片版本。下线或撤权阻止依赖图片的后续读取。设计器打印配置可以引用图片版本或绑定批准字段生成QR/Code128，参数、URL和登录令牌不允许进入条码。

打印配置支持横向纸张、分组、小计和重复页脚；固定区始终绑定原始业务行。服务器计划的media坐标由浏览器纸张、PDF和样式XLSX复用。批次固定每份DOCUMENT的发布版本和参数，最多50份，逐份鉴权和入队；每份状态在批次/导出中心查看。现场打印机、扫码器和真实纸张需人工验收。

## E5 仪表盘

“个人仪表盘”保存和发布独立版本，每个组件固定报告发布版本和参数。支持指标、柱状图、折线图、饼图、表格和交叉表。指标、变化率及图表归一化投影由服务器精确计算，提示保留原始字符串数值；比较期必须使用相同聚合分区。

每个组件独立显示来源时点、一致性及失败状态；表格预览明确最多200行，完整来源最多5000行。组件间参数联动只传递已批准的typed value。清除筛选会废弃在途旧结果；页面隐藏或用户暂停时停止刷新。收藏仅保留个人选择，不授予访问权。全局/租户/用户默认刷新上限1200/120/12次每分钟，主库计数。

## E6 私有共享存储与治理

LOCAL仍为默认，storage.manifestEnabled默认false以兼容仅安装P0/E0/E1的环境。安装扩展结构后可启用清单硬配额；S3要求manifestEnabled=true、专用私有桶、相同逻辑storageId和独立节点暂存目录。专用桶必须从未启用版本功能，且没有启用的自动生命周期；应用验证ACL、策略、版本和生命周期，全部读取走正常认证的应用代理。

默认全局16GiB/10000业务对象、每租户2GiB/2000业务对象。暂存、上传和物化先保留容量，删除物理确认后才释放。对象的一次性引用有永久封存围栏：本地.fences文件锁/1字节标志，S3原子零字节retired对象；这些是不可下载的围栏元数据，应保留，不能用外部生命周期删除。业务对象配额按清单计数，围栏元数据不作为可下载业务对象计入。删除意图先提交，物理IO不持有全局数据库锁；旧上传与旧删除不能恢复已封存引用或重新pin待删字体。

清单恢复按不可变租户/引用游标推进，暂存只能由同一稳定节点持有者清理；外节点不会删除foreign staging。快照索引按512行/约1MiB分块校验并使用本地seek或S3 Range；字体按租户checksum共享、读取租约及计划引用防回收。执行并发默认全局8/租户2/用户1，入队上限用户50/租户100/全局1000，候选在LIMIT前排除饱和租户。

## E7 订阅与私有交付

“报表订阅”固定报告发布版本、格式、最多20名接收人、明确ZoneId及白名单参数规则（固定值、日期相对值、接收人ID）。cron至少间隔5分钟；夏令时缺失时刻跳过，重叠时只取较早offset一次。补跑最多24小时、默认单批20次；catchupSeconds=0仍允许120秒正常调度抖动，不对更久的历史时刻补跑。

调度和真实站内通知默认关闭；手动运行及已有outbox维护不依赖新cron开关。每名接收人使用自己的当前权限，创建者权限和发布时范围也会复核。省略的provider日期默认值在区间校验前按计划Instant/timezone冻结，延迟重试不使用执行当天。单次手动请求先冻结整体occurrence，再登记原接收人集合，重复键不会因重新发布增加接收人。

每份交付使用独立持久执行及导出作业，队列满保留RETRY_WAIT，其他接收人继续；取消终态不能被失败补偿覆盖。领取及通用导出下载都复核来源、接收人权限、状态和过期。通知开关仅控制消息发送，不停用已发布订阅或使文件失效。真实通知本轮未发送；站内通知打开后还须验收既有IM通道。

## 一期业务单据设计与打印（2026-10-17）

### 纸张与固定网格

在设计器“纸张与分页”选择A4、A5或自定义尺寸及横竖方向，纸张、边距、行高和列宽均以毫米输入，字号仍按印刷点数显示。定义内部继续使用pt，旧版不因设置纸张自动升级；第二版方向只交换一次实际宽高。纸张改变会按原列宽比例适配，不能容纳最小列宽或导致媒体越界时保留原设置并提示。

画布提供毫米标尺、缩放和“适应宽度”。拖动列边界调整相邻列，保持总宽；拖动固定行底边改变行高。每次拖动在松开时提交一次，按Esc或取消指针操作丢弃未提交结果，撤销不会逐帧回放。Shift+点击在同一页眉或页脚中建立矩形，支持合并、拆分和批量样式；不能截断已有跨格或跨越明细区。合并保留左上格内容，撤销可恢复原内容。删除涉及跨行合并的固定行前需先拆分。

画布中的明细是结构占位，实际文本换行、页数和分页仍以服务端预览为准。草稿预览保持最多200行；设计或条件变化会使旧预览失效。正式运行与打印固定同一已发布版本和快照，浏览器不重算金额、数量或分页。

### 私有图片与条码

在“打印扩展”显式开启第二版打印，然后添加QR、Code128或从图库选择当前可访问的已发布图片。图片选择显示名称、缩略图及像素尺寸，绑定固定版本；需要图片目录权限，实际读取和发布仍受资源ACL检查。图库可搜索，每次显示前24项。图片或条码可在画布拖动、缩放，也可输入毫米坐标；二维码保持正方形，所有媒体限制在可打印范围内。条码只绑定批准的业务编码字段，不能填入URL或登录令牌。

在画布选中列、固定格、同区域矩形或媒体后，右侧只显示相应属性和操作。媒体位置及打印尺寸以毫米显示，图片本身尺寸标明为像素；普通输入在Enter或失焦时提交，多行文本使用Ctrl+Enter；数字加减按钮立即提交，重复失焦不重复记录。固定版本图片重新打开时会读取当前授权名称和该版本尺寸；撤权、下线或读取失败时提示不可访问，不自动替换为最新版本。

媒体选中且焦点不在输入控件中时，方向键移动0.5mm，Shift加方向键移动5mm；一次连续按键或拖动只形成一次历史。Escape先取消当前候选移动；没有活动候选时，已展开的选择器先消费Escape，之后才关闭侧栏、退出专注编辑。输入法组合输入保留自身行为。缩放、选区、辅助线、侧栏和专注模式不会保存进报表定义。

### 四类业务入口与单张打印

采购订单、销售订单、送货单和采购收货单列表均提供行内“预览/打印”和工具栏批量入口。选择可访问的单据模板后，在当前列表内打开预览抽屉，带入完整单据ID并自动发起一次固定快照预览；列表筛选和勾选保留。“打开完整页”会重新鉴权并复用当前run，不再次创建业务快照。若模板发布版本已变化，服务端在取数前拒绝创建运行，需重新选择模板。

运行页“打印PDF”使用当前运行创建导出任务；完成后预览同一任务文件，可通过浏览器PDF查看器进入系统打印对话框。正在生成时显示状态，可恢复失败沿用该任务重试。条件变化、离开页面或切换账号后，迟到结果不会打开旧文件。

销售订单和采购收货单新增固定数据集及基础模板，完整权限下代码目录现支持16个固定数据集、19类基础模板。管理员通过“创建基础报表”显式增量初始化，原有同编码定义、修订、发布状态和用户修改不会被覆盖。本轮代码更新未自动向现有环境写入模板。

### 列表多选与合并PDF

一次选择1至50份单据，确认模板、批次标题和顺序后创建；可上移、下移调整提交顺序。批量页面也可使用固定版本的参数表单与业务选择器逐项配置。网络失败后重试保留原批次code和内容；创建成功而入队失败时，只补充入队，不再创建另一批次。

列表内批量确认优先显示单号、客户或供应商，并保留完整标识。提交成功后原位显示逐项结果；关闭只停止本地观察，不取消后台任务。重新打开继续显示同一批次；若创建结果未知，重试沿用原code和冻结内容。已有冻结提交时，清空或超量勾选仍可通过“继续原批次”恢复。勾选改变后，可先核对原批次，再通过“新建其他批次”明确采用新的选择。离开业务页后，可从批次页打开已知batchId；提交参数不写入浏览器持久存储。

每份单据独立鉴权、生成固定快照并导出PDF。批次详情提供逐项状态和错误，未入队项使用“补充入队”，可恢复的导出失败使用原任务重试；取消、过期或不可恢复的单据需重新准备批次。各单据的快照时间可能不同。

全部成功且仍有权限时，批次创建者可预览或下载合并PDF。文件按最终提交顺序拼接，保持各单据独立起页、原纸张尺寸和单据内页码。任一失败、未完成、过期或撤权都会阻止完整领取，不会跳过该份单据。合并只读取已有PDF，不重查业务数据；产物按需生成、私有交付且不持久缓存。

合并输入总量与输出大小分别受`nexus.report.max-artifact-bytes`限制（默认100MiB）。`nexus.report.batch.max-pages`默认及上限为1000页，`nexus.report.batch.merge-seconds`默认及上限为60秒，合并与流式交付共享该期限；检查点之间的单次阻塞仍受底层存储和服务器超时控制。文件请求沿用120秒超时；超限时缩小批次。实际打印机纸张、缩放和打印效果需在目标设备另行验收。

### 状态恢复与开发回归

版本变化需要重新选择模板；文件或快照过期需要明确创建新运行或批次；权限变化会关闭旧文件入口并清除不能继续展示的结果。已打开的合并PDF在逐项状态确认不可领取后会回收缓存；撤权单据不再展示原单号、往来单位和完整标识，返回确认页也不会恢复旧标签。未入队项使用补入队，可恢复导出失败使用原任务及显示轮次；普通网络异常保留原提交供核对，不自动重发写请求。JSON错误文件不会作为PDF交给查看器。

开发环境在 `plus-ui/` 执行 `npm run test:report:browser`，通过独立Vite、合成API和隔离Edge/Chrome验证实际组件，无需启动业务后端。可用 `REPORT_TEST_BROWSER` 指定浏览器；浏览器或原生WebSocket能力缺失时命令明确失败。测试生成物写入忽略目录，任务结束清理自身进程；该UI回归不代替真实数据库、S3、生产部署或打印机验收。
