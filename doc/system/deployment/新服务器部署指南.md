## 快速更新（仅主服务器业务服务）
完整步骤见《docker部署文档.md》第十二节。要点：
- 后端：`docker build -t nexus-erp:fix-headless ./ruoyi-admin && docker compose -f docker-compose-main.yml up -d --force-recreate nexus-server`
- 前端：替换 `/docker/nginx/html/dist` 后 `docker exec nexus-nginx nginx -s reload`
- ⚠️ `docker restart` 不会使用新镜像，必须 `--force-recreate`
- 辅助服务器（Monitor/SnailJob）不在本次更新范围
