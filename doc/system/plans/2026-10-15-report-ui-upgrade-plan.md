# 报表前端界面升级实施计划

日期：2026-10-15；基线：codex/report-module-plan / 49778ea3。

**目标：** 在保留现有 API、权限、发布版本及精确值语义的基础上，统一全部 13 个报表页面，改善查找、设计、运行和领取流程。

**架构：** 复用 Vue 3、Element Plus 和现有主题变量。新增 ReportPage 页面容器、ReportStatus 状态标签及 presentation.ts 展示辅助函数；样式限制在报表页面内，不改全站主题。列表计数仅反映当前接口返回且可见的资源，业务值仍由服务器提供。

**方案选择：** 局部更换颜色无法解决操作密度；整体引入新组件库会增加依赖和风格割裂。采用现有组件上的统一工作台布局：轻量页头、明确主操作、目录侧栏、筛选工具条和内容分区。

## 实施步骤

- [x]   1. 建立展示层测试。新增 test-report-presentation.mjs，覆盖名称/编码搜索、类型/状态/目录组合、完整字符串 ID、无匹配、统计计数和未知状态回退；先运行确认失败，再实现展示辅助函数。
- [x]   2. 建立共享容器和状态组件。ReportPage.vue 提供页头及操作插槽；ReportStatus.vue 统一草稿/发布/排队/交付等中文状态；report-ui.scss 仅作用于 .report-page，使用 Element Plus 变量，提供焦点、换行、窄屏和深色模式适配。
- [x]   3. 重构报表中心。目录导航与可见数量、状态筛选、列表/卡片切换、清空筛选和有针对性的空状态；将运行和设计作为常用操作，维护操作收纳到更多菜单，逐项保留权限指令；补齐 PIVOT 筛选及入口；快捷入口排除404兜底匹配，适配尚未安装扩展菜单的环境。
- [x]   4. 优化设计器和运行页。设计器增加按标签/绑定名/类型搜索字段、键盘添加和无匹配提示；保留撤销/重做、修订、离页确认和草稿预览。运行页拆分参数与结果、保留固定快照提示、增加未运行及失败状态；不在浏览器计算报表金额、汇总或比率。
- [x]   5. 统一其余页面。数据集、查询、交叉报表、图片、批次、仪表盘、导出、发布历史、订阅与我的交付使用共享页头、中文状态、内容分节、加载和空状态。仪表盘运行/编辑流程、自动暂停与联动保持现状；不启用服务器能力开关。
- [x]   6. 增补真实组件交互测试。验证中心组合筛选与清空、字段搜索及空匹配；沿用现有隔离 API 挂载测试验证权限敏感业务操作与竞态保护。
- [x]   7. 视觉验收。通过端口 18087 的隔离合成数据预览运行实际组件，核对桌面、窄屏、深色以及空/失败状态；截图放入 doc/system/assets/report-ui/，明确标注合成数据。
- [x]   8. 验证交付。在 plus-ui 下运行 npm run test:report、npm run test:unit、npm run type-check、npm run build:prod，针对修改文件执行 ESLint/Prettier；记录用例数、结果和限制，检查 git diff；不修改目标数据库，不推送。

## 完成标准

所有页面有清晰标题和主要动作；用户能从中心筛选 TABLE / DOCUMENT / PIVOT 并运行或设计，能区分无数据与筛选无结果；窄屏不使整页横向溢出（复杂表格在容器内滚动）；深色模式不残留浅色硬编码面板；业务权限和精确字符串值不变。所有新增函数、组件契约和状态使用中文 JSDoc，数据库、后端与真实通知不在本次改动范围内。
