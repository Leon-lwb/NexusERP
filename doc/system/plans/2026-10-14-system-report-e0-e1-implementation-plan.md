## 实施边界

本轮保持 DSL v1 / engine 1.0.0 为唯一正式能力；兼容测试安装受控测试执行器证明分发，不代表新增 v2 语法。版本/lookup/executor 均由代码注册；正常登录、租户、资源 ACL 和业务范围继续同时生效。

T03 以列编辑和现有固定区域控件为交付边界；未新增自由画布吸附、整行多选或任意区域复制。日期区间沿用两个已声明 DATE 参数；六类选择器提供独立查询与分页，未新增层级联动协议。E2+ 查询目录、交叉表、图片、仪表盘、共享存储与订阅不混入本轮。

使用现有fixture和受控合成资源。Maven串行构建；本机只执行新增五列的E0/E1增量，没有重导主SQL或重复清理积木表。主SQL仅增加五行。本轮启动的测试资源已限定清理，原生六类模板与六个业务数据集保留。
