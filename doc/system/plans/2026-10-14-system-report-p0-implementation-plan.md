## 已确定的交付边界

TABLE 与 DOCUMENT 两种模板，自有 v1 DSL 与扩展 SPI；可信业务数据集、资源 ACL、租户/组织/列权限；草稿乐观锁、不可变发布/回滚/下线；服务器布局与精确计算；同次快照的预览/PDF/明细与样式 XLSX；持久、幂等、可取消的导出任务；原生 Vue 3 设计器与运行界面；六类业务初始模板。P1/P2 的查询目录、交叉表、仪表盘、订阅和分享不在本次实施范围。

默认使用应用服务代理访问的私有文件存储，存储接口独立，预留私有对象存储实现；不使用现有可能公开的附件 URL 交付业务快照。生产集群启用共享存储前必须验证同一存储接口。

## 文件范围

- `ruoyi-common/ruoyi-common-report`：纯 Java/Jackson 契约与通用查询范围；加入 common/根依赖管理。
- `ruoyi-modules/ruoyi-report`：复用模块名，包 `com.nexus.report`；config/domain/mapper/service/controller、engine/runtime/export/storage 子包。
- `ruoyi-system`、`ruoyi-erp`、`ruoyi-mes`：`report/adapter`，只依赖 common-report；不依赖报表业务引擎。
- `plus-ui/src/api/report`、`src/types/report`、`src/views/report`、`src/components/report`：自有模型和原生界面。
- `script/sql/ry-vue.sql` 与本次增量脚本；现有业务 SQL 定义保留。
- `doc/system`：更新设计/路线并新增首期实际执行记录。
