## 3. 执行中发现并修复的脚本缺陷（7 类）

> 这些是**脚本本身的缺陷**，在"只写文件不执行"时无法发现；已全部修复并复跑验证。

### 3.1 8 个脚本的 ry-vue 表未加库名前缀
`sch-cv` / `erp-p2` / `fin-fix` / `mes-eq` / `mes-p2` / `tg-sop` / `mes-spare-erp` / `iot-ota`
在指定默认库为 `ry-erp`/`ry-mes`/`ry-iot` 时，其 `sys_menu`/`sys_dict_*`/`sys_role_menu`/`sj_job*` 语句会落到错误库并报
`Table 'ry-erp.sys_menu' doesn't exist`。**已全部改为 `` `ry-vue`.`表名` ``（含子查询里的 `FROM`/`JOIN`）**。

### 3.2 `uk-tenant-dimension` 的 `_nexus_add_uk` 缺"表不在当前库"判断
该过程原先只查索引是否存在，跨库执行时对不属于当前库的表直接 `ALTER` → 报错并**中断整个脚本**（导致后半段语句不执行）。
**已加表存在性检查**：表不在当前库 → 打印 `[SKIP] ... 请在对应库重跑本脚本`，因此现在可以安全地按库跑两次。

### 3.3 `wm-core` 的 `uk_stock_dim` 使用表达式索引（MySQL 5.7 不支持）
`ADD UNIQUE KEY ... (tenant_id, material_id, (IFNULL(batch_id,0)), ...)` 是 MySQL **8.0.13+** 的表达式索引语法，
5.7 报 `ERROR 1064`。**已改为按版本条件执行**：8.0+ 才建该索引，5.7 打印 `[SKIP] ... 需改用生成列方案`。
→ 见 §4.1（仍未生效，属已知待办）。

### 3.4 `fe-erp-dict-seeds` 引用了不存在的列
`sys_dict_type` 与 `sys_dict_data` **都没有 `status` 列**，脚本却按 `(..., status, ...)` 插入 → `ERROR 1054 Unknown column 'status'`；
且未限定库名、未给显式主键。**已按两表真实列定义重写**（显式 `dict_id`/`dict_code`、加库名前缀、`INSERT IGNORE`），
并**同步修正了主脚本 `ry-vue.sql` 中由我合并的同名块**（同一缺陷，会影响全新环境导入）。

### 3.5 `sch-cv` 的 5 处守卫恒为假 → ALTER 从不执行（**静默空转，最隐蔽**）
脚本写法为 `SET @ddl := (SELECT IF(COUNT(*) = 0, 'ALTER TABLE ...', 'SELECT 1'))` ——
这个 `SELECT COUNT(*)` **没有 FROM 子句**，标量子查询恒返回 1，所以条件恒为假、**永远走 `SELECT 1` 分支**，
`face_verify_attempts` / `face_verify_last_attempt_time` 两列与 `idx_face_verify_backfill` 索引**从未建立**，
但脚本"执行成功、无报错"。**已改为 `information_schema.COLUMNS`/`STATISTICS` 子查询**，修复后两列一索引正常建立。
（已全仓扫描其余脚本：只有 `sch-cv` 存在该写法，其余 5 个脚本的守卫都带 `FROM information_schema`。）

### 3.6 `pu-prd-bd` 的 `bd_supply_type` 字典只写在注释里
脚本注释声明"新增字典 `bd_supply_type`"，但**没有任何插入语句** → 存量库缺该字典，BOM 明细「供应方」下拉为空。
**已补齐**（1 个 dict_type + 3 条 dict_data，`dict_id=600260`、`dict_code=600261-600263`）。

### 3.7 `mes-p2` 的 X_MR 字典主键与现网数据冲突
脚本给 `spc_chart_type.X_MR` 用的 `dict_code=2068956987053351027` **已被现网 `mes_enable_status/ACTIVE` 占用**，
而幂等守卫只查 `(dict_type, dict_value)` 不查主键 → 报 `Duplicate entry ... for key 'PRIMARY'`。
**已改用空闲的 `600252`**（主脚本 `ry-vue.sql` 中同一行同步修正），修复后幂等复跑通过。
