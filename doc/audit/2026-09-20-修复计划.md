## 3. 修复批次与依赖关系

- **并行安全**：B1/B3（同属 iot 但文件不重叠）、B4/B5/B6/B7/B8 文件均不重叠。
  **同模块并发跑 maven 会有 `target/` 争用** → 各代理只跑"自己的测试类"，全量测试由主代理最后统一跑。
- **串行依赖**：
  - `script/sql/ry-vue.sql`、`ry-erp.sql`、`ry-mes.sql`、`doc/system/数据库增量变更记录.md` 为**独占文件**，
    各代理只写自己的 `script/sql/update/2026-09-20-*.sql` 并在报告里给「主脚本合并清单」，
    由主代理**串行合并**（见修复规范 §1.1）。
  - B9 前端依赖 FE 审计完成；IoT 功能补齐（B10）依赖 B3 完成（同文件）。
- **B10 功能补齐**（用户要求尽可能全部实现，按可行性排序）：
  1. IoT 告警落库 + 确认/恢复状态机（IOT-ALERT-01）
  2. IoT 设备分组/标签 + 设备生命周期（激活/禁用/注销）+ 密钥轮换（IOT-DEV-01、IOT-MQTT-05）
  3. IoT 事件上报 `event/post` + 下行 `property/set`（IOT-PIPE-02）
  4. IoT 告警规则 CRUD（IOT-ALERT-02）
  5. MES 备件与 ERP 库存打通（MES-EQ-04，需 DDL + 跨模块）
  6. OEE 口径接真实数据（MES-EQ-03）
  7. 设备影子/期望值、数据转发（HTTP/MQ）
  8. IoT OTA 固件升级（最大件，MVP：固件登记 + 下发任务 + 设备回报 + 版本核对）
  9. 电子签名 + DHR 批记录（合规大件）
  10. MES 工单取消/关闭死状态、返工状态机闭环（MES-PRO-11、MES-X-02）
