# 备件编码纠正与工装业务数据 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 MES 备件增加正式自动编码规则，通过受控接口全量纠正 ERP 物料、ERP 仓库和 MES 备件编码及历史快照，并生成工装管理四菜单的完整业务数据。

**Architecture:** 自动编码仍由 master 数据源的 `AutoCodeUtil` 统一取号；三个业务数据源纠正服务分别在 ERP/MES 本地事务中以当前编码 CAS 更新主表和所有冗余快照。业务数据使用持久化单次派发脚本调用正常 API，工装领用、归还、保养和校准全部经过现有状态机。

**Tech Stack:** Java 17、Spring Boot 3.5、MyBatis-Plus、Lock4j、dynamic-datasource、JUnit 5、Mockito、Vue 3、TypeScript、Node test、MySQL 5.7、本地 REST API。
