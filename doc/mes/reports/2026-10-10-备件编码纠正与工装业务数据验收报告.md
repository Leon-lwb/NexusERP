## 4. 前端修复

浏览器验收发现工装保养计划、保养记录和使用记录页面直接展示 19 位 `toolingId`。本次增加共享工装引用映射，三页一次批量读取工装台账，并显示“正式编码 · 工装名称”。同时收紧非关键列宽，使三个工装业务列表在 1440 像素桌面视口下无需表格横向滚动。

新增回归覆盖：

- 雪花 ID 统一转字符串后匹配，避免数字/字符串类型差异。
- 映射命中时显示编码和名称，映射缺失时保留可追溯 ID。
- 三个页面不再使用“工装ID”列或把 ID 当作工装编码。
- 新回归已接入标准 `npm run test:unit`。
