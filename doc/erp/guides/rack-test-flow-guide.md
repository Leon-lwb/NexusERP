# 简易金属工具架(RACK-001) 手工测试流程指南

## 前置条件

1. 确保系统已启动（后端 + 前端）
2. 登录系统（默认 admin/admin123）
3. 先执行 SQL 脚本 `script/sql/rack-test-data-init.sql` 导入基础数据

## 第二阶段：采购流程

### 2.1 创建采购申请
- 入口：**采购管理 → 采购申请**
- 操作：新增
- 填写：
  - 申请日期：今天
  - 明细1：物料=钢板(STEEL-PLATE)，数量=100 kg，单价=4.5元，需求日期=3天后
  - 明细2：物料=连接件包(RACK-FIT)，数量=50 套，单价=12元，需求日期=3天后
- 保存 → 提交审批

### 2.2 审批采购申请
- 入口：**流程中心**（如启用工作流）或采购申请列表直接"审核通过"
- 状态变为"已审批"

### 2.3 转采购订单
- 入口：**采购管理 → 采购订单**
- 操作：从采购申请生成采购订单（或手动新增）
- 确认供应商：
  - 钢板 → 钢板产出商(V00001)
  - 连接件包 → 宏达五金(V00005)
- 保存 → 提交审批

### 2.4 审批采购订单
- 审核通过，状态变为"已审批"

### 2.5 创建到货通知
- 入口：**仓储管理 → 到货通知**（或采购管理中的到货通知）
- 操作：新增，选择采购订单
- 确认物料和数量与采购订单一致
- 保存

### 2.6 来料检验 IQC
- 入口：**质量管理 → 来料检验(IQC)**
- 操作：对到货的钢板和连接件包分别进行检验
  - 钢板：抽样10%，肉眼检查外观 + 尺寸测量 → 合格
  - 连接件包：抽样10%，检查数量及外观 → 合格
- 填写检验结果→ 合格 → 完成

### 2.7 采购入库
- 入口：**仓储管理 → 采购入库**
- 操作：
  - 选择到货通知单号
  - 确认钢板入库 → 仓库: 原料仓库，库区: 金属库区，库位: 钢板库位
  - 确认连接件包入库 → 仓库: 原料仓库，库区: 辅料库区
- 保存，确认入库
- **验证**：去 **库存管理 → 库存查询** 查看钢板和连接件包的库存已增加

## 第三阶段：生产流程

### 3.1 创建生产计划
- 入口：**生产管理 → 生产计划**
- 操作：新增
  - 计划编号：自动生成
  - 计划日期：今天
  - 计划明细：选择物料=RACK-001 简易金属工具架，数量=20
  - 计划开始日期：今天；计划结束日期：3天后
  - 保存
- 提交审批 → 审核通过

### 3.2 展开物料需求（MRP）
- 入口：**生产管理 → 物料需求**（或在生产计划页面点击"展开MRP"）
- 系统自动根据BOM展开：
  - 侧板组件(RACK-SIDE)：20台×2件=40件（自制）
    - 钢板：40件×1.5kg×(1+2%损耗)=61.2kg（外购→需检查库存是否足够）
  - 连接件包(RACK-FIT)：20台×1套=20套（外购）

### 3.3 创建工单
- 入口：**生产管理 → 工单管理**
- 操作：
  - 新增，来源=生产计划，选择刚创建的计划
  - 物料=RACK-001，数量=20
  - 工艺路线=RT-RACK-001
  - 计划开始时间=明天，计划结束时间=3天后
  - 车间=冲压车间#1（或注塑车间#1）
  - 保存

### 3.4 提交/审批工单
- 在工单列表页，勾选该工单 → 提交审批
- 审批通过后，工单状态变为"已审批"

### 3.5 下达工单（触发MES）
- 在工单列表页，点击"下达"按钮
- 系统通过MQ消息将工单推送到MES模块
- **验证**：进入 **MES → MES工单**，应能查看到新创建的MES工单（状态=已创建）

### 3.6 创建MBOM（如SQL已导入则跳过）
- 入口：**MES → MBOM管理**
- 如果SQL已导入MBOM(v1.0)，确认状态为"启用"
- 如未导入，手动创建MBOM，关联BOM和工艺路线

### 3.7 MES工单释放
- 入口：**MES → MES工单**
- 操作：选择工单 → 点击"释放"
- MES工单状态变为"已释放"，自动生成工序步骤（CUT→WELD→ASM→PKG）
- **验证**：查看工单详情，能看到4个工序步骤

### 3.8 生产领料
- 入口：**仓储管理 → 生产领料**
- 操作：
  - 新增，选择工单号
  - 确认领料明细（系统自动列出BOM中所有物料）
  - 钢板：60 kg（按BOM用量，扣除2%损耗预留）
  - 连接件包：20 套
  - 仓库：原料仓库
  - 提交 → 确认出库
- **验证**：库存查询 → 钢板和连接件包已减少

### 3.9 创建流转卡
- 入口：**MES → 流转卡管理**
- 操作：新增，选择MES工单
  - 计划数量：20
  - 分配至工作站和操作员
  - 保存，流转卡状态=已创建
- 点击"下达"，流转卡状态变为"已下达"

### 3.10 工序1：切割(CUT) — 派工报工
- 入口：**MES → 派工管理**
- 操作：
  - 新增派工单，选择流转卡，工序=CUT
  - 派工给操作员（选择一个已有的工人）
  - 计划数量：40件（20台×2侧板）
  - 下达派工

### 3.11 切割报工
- 入口：**MES → 流转卡管理** → 点"报工"
  - 工序=CUT
  - 完工数量=40，合格数量=40，报废=0
  - 实际工时：约12小时（40件×0.3h）
  - 提交

### 3.12 工序2：焊接(WELD) — 派工报工
- 同3.10操作，工序=WELD
- 派工给焊接工
- 计划数量：40件

### 3.13 焊接报工 + IPQC
- 报工：完工40件，合格38件，报废2件（模拟不良场景）
- 实际工时：约20小时（40件×0.5h）
- 焊接是关键工序，提交报工后系统自动触发**过程检验(IPQC)**
- 入口：**质量管理 → 过程检验(IPQC)**
  - 应能看到一条IPQC记录，关联该工单和焊接工序
  - 对焊点进行抽查 → 填写结果 → 合格
  - IPQC完成
- 该工序步骤完成，流转卡自动流转到下一工序

### 3.14 工序3：装配(ASM) — 派工报工
- 派工给装配工，工序=ASM
- 计划数量：19台（基于38件侧板/2=19台）
- 报工：完工19台，合格19台，报废0
- 实际工时：约5.7小时（19台×0.3h）

### 3.15 工序4：包装(PKG) — 派工报工
- 派工给包装工，工序=PKG
- 计划数量：19台
- 报工：完工19台，合格19台，报废0
- 实际工时：约2.85小时（19台×0.15h）

### 3.16 工单完工
- 入口：**MES → MES工单**
- 操作：选择工单 → 点击"完工"
- 状态变为"已完成"
- 系统自动通知ERP工单完成（MQ消息）

### 3.17 成品入库
- 入口：**仓储管理 → 成品入库**（或生产入库）
- 操作：
  - 选择工单号
  - 确认成品：RACK-001 工具架，数量=19台
  - 入库仓库：成品仓库，库区：成品区，库位：选择或新增工具架库位
  - 确认入库
- **验证**：库存查询 → 工具架库存：19台

### 3.18 查看报工记录
- 入口：**生产管理 → 报工记录**（或MES → 报工记录）
- 确认CUT/WELD/ASM/PKG四条报工记录，数据正确

## 常见问题

**Q: 创建采购订单时找不到供应商？**
A: 确认供应商(V00005 宏达五金)已创建，且物料-供应商关系(BdMaterialVendor)已建立。

**Q: MES工单没有自动创建？**
A: 检查MQ配置是否正常。可手动在MES工单页面创建（选择关联ERP工单）。

**Q: 库存不足无法领料？**
A: 减少生产计划数量，或先补采购。

**Q: 流转卡步骤无法流转？**
A: 确认上一工序已完成报工且IPQC（关键工序）已通过。
