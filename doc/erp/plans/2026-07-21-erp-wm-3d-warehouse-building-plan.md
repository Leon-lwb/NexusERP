## 概述

**Goal:** 当前 3D 视图只渲染库区半透明框 + 库位立方体，**没有"仓库"这栋建筑本体**。本计划在库区之外自动包络出一栋**写实厂房**（地台 + 实墙 + 门洞 + 窗带 + 人字屋顶），让 3D 视图能直观看到"这是一座仓库"，同时不破坏既有的内部库位查看与交互。

**决策摘要（2026-07-21 用户确认）：**

| 决策点 | 选择 | 影响 |
|--------|------|------|
| 建筑尺寸/定位来源 | **自动包络** | 由内容包围盒 `bounds` 推导占地/墙高/屋顶，纯前端、零后端/DDL 改动；换仓库数据自动适配 |
| 视觉风格 | **写实厂房** | 地台+实墙+门洞+窗带+人字屋顶；不写 GLTF、不做 CSG |
| 遮挡/显隐策略 | **屋顶自动隐藏** | 相机俯视/拉近时隐藏屋顶见内部，低角度恢复；工具栏加"外壳"总开关 |

**关键约束（沿用既有实现）：** raycast 拾取目标原为 `locationMeshes`。本计划让建筑网格**参与遮挡拾取但不响应业务交互**（最近命中为建筑则不触发库位 tooltip/钻取），保证"看得到才点得到"，避免隔墙触发库位浮窗。

**Tech Stack:** 沿用 Three.js + Vue 3.5 + TS；纯前端，后端/数据库零改动。

## 一、设计

### 1. 建筑轮廓推导（自动包络）

复用 `3d.vue` 建场景时已算出的内容包围盒 `bounds`（minX..maxX / minY..maxY / minZ..maxZ）：

- 占地：`W = (maxX-minX) + 2×边距`，`D = (maxZ-minZ) + 2×边距`，中心取包围盒中心（边距 `MARGIN=2m`）
- 墙高：`wallH = max(maxY, MIN_WALL_H=4) + WALL_CLEARANCE=1.5`
- 屋顶：人字坡，屋脊沿较长轴，出檐 `ROOF_OVER=0.6`，坡角 `28°`，起坡 `rise = (短跨/2 + 出檐) × tan(28°)`
- 空仓库（`bounds` 非有限值）→ 返回 `null`，跳过建筑

演示仓（WH-3D-DEMO）粗算：内容 x∈[-3,11]、z∈[-2,2]、y∈[0,3] → 占地约 18×8m、墙高 5.5m、屋顶脊高 ≈7.95m，比例协调。

### 2. 几何构件（全部 Box/ExtrudeGeometry + MeshStandardMaterial）

| 构件 | 做法 | 材质 |
|------|------|------|
| 地台 | 略大于占地的扁盒，顶面抬 1cm 避免与地面网格 z-fighting | 水泥灰 `#b7bcc3` |
| 两侧墙 + 背墙 | 带厚度实墙（`WALL_T=0.2`） | 米白 `#e9ebee` |
| 前墙（+Z） | 分段拼装留门洞：左段 + 右段 + 门楣（无需布尔） | 米白 |
| 卷帘门 | 门洞内略凹的色板（闭合写实门） | 灰 `#8b939c` |
| 窗带 | 两侧墙 + 背墙近墙顶贴半透明玻璃长条（表面贴面不开孔） | 浅蓝 `#9fd0e8` 半透明 |
| 人字屋顶 | `THREE.Shape` 三角形 → `ExtrudeGeometry` 三棱柱（含前后山墙），`center()` 后按屋脊轴旋转 | 钢蓝灰 `#7086a0` |

门洞尺寸按建筑宽度钳制（`doorW = min(3, width×0.4)`，`doorH = min(3.2, wallH-0.8)`）。

### 3. 遮挡与交互（核心）

- 建筑网格**加入 raycast 目标列表**（与 `locationMeshes` 一起），取**最近命中**：命中库位才触发 tooltip/钻取/聚焦，命中建筑或空白则不动作 → "看得到才点得到"。
- **有效可见性** `isEffVisible`：沿父链检查 `.visible`，任一祖先不可见即视为不可见。命中结果先按有效可见性过滤，保证屋顶/外壳隐藏后不遮挡也不误拾取。
- **屋顶自动隐藏**：`animate()` 内按相机相对 `controls.target` 的俯仰角判断，俯角 > 42° 隐藏屋顶、< 32° 恢复（10° 迟滞防抖）。
- **"外壳"开关**：工具栏 `el-checkbox`，关闭时整栋（墙+顶+地台）`group.visible=false`，回到纯内部视图；数据重载后按开关状态重新应用。
- **初始取景**：`frameBounds` 的包围盒扩展到整栋厂房轮廓，`重置视角`同样覆盖整栋。

### 4. 释放

建筑挂进 `scene`，现有 `disposeScene` 的 `scene.traverse` 统一 dispose 其 geometry/material；`disposeScene` 额外重置 `buildingGroup / roofMesh / buildingPickMeshes / roofHidden`。

## 四、风险与应对

| 风险 | 应对 |
|------|------|
| 屋顶挤出方向/屋脊朝向错误 | `ridgeAlongX` 二分 + `center()` 定位，运行时目测，朝向不对仅调 `rotation.y` 一处 |
| 隔墙误触发库位浮窗 | 建筑网格入遮挡拾取 + 有效可见性过滤，最近命中为建筑则不动作 |
| 屋顶显隐在阈值边界抖动 | 42°/32° 双阈值迟滞 |
| 外壳隐藏后仍遮挡内部拾取 | `isEffVisible` 沿父链判断，外壳不可见时不参与遮挡 |
| 透明窗带深度排序异常 | 窗带贴墙表面、区域小，默认 depthWrite，影响可忽略 |
