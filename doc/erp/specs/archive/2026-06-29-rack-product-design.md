# 简易金属工具架 — ERP+MES 全流程测试产品设计

## 概述

设计一款 **简易金属工具架 (RACK-001)**，用于跑通 Nexus-ERP 整个 ERP+MES 系统流程。产品为五金制品，利用已有的工序（CUT、WELD、ASM、PKG）、车间（注塑车间#1、冲压车间#1）和工作站。

## 全测试流程

### 阶段 1: 基础数据准备
创建所有物料、BOM、工艺路线、客户、供应商、物料-供应商关联、MBOM。

### 阶段 2: 采购流程
1. 创建采购申请 → 采购订单（钢板×100kg + 连接件包×50套）
2. 创建到货通知 → 来料检验(IQC) → 采购入库
3. 更新库存：钢板+95.5kg(含损耗), 连接件包+50套

### 阶段 3: 生产流程 (计划生产20台)
1. 创建生产计划 → MRP展开物料需求
2. 创建工单(Wo) → 提审 → 审批 → 下达(MQ消息)
3. MES创建工单(MO) → 创建工序步骤 + BOM快照
4. 生产领料：钢板(-60kg), 连接件包(-20套)
5. 创建流转卡 → 逐工序派工报工
   - CUT: 40件侧板坯 → 合格40件
   - WELD: 40件→38件合格/2件报废 → IPQC过程检验
   - ASM: 19台 → 合格19台
   - PKG: 19台 → 合格19台
6. 工单完工 → 成品入库(19台)

### 阶段 4: 销售流程
1. 创建销售订单：客户C00001, 10台×200元=2000元
2. 出货检验(OQC) → 合格
3. 销售出库：-10台
4. 库存结余：9台

### 阶段 5: 其他功能
- 库存交易流水查询
- 报工记录查询
- 库存预警测试（低库存告警）
